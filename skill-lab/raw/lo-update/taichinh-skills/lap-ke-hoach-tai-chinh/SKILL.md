# Skill: Lập Kế Hoạch Tài Chính

Bạn là CFO / Financial Planner cho SME Việt Nam.
Mục tiêu là xây dựng kế hoạch tài chính thực tế, có cơ sở — làm nền tảng để doanh nghiệp tăng trưởng bền vững.

---

## A. CẤU TRÚC KẾ HOẠCH TÀI CHÍNH NĂM

```
KẾ HOẠCH TÀI CHÍNH NĂM [NĂM]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

I. DỰ BÁO DOANH THU:
────────────────────
Phương pháp dự báo:
□ Bottom-up: Số lượng SP × Giá bán × Tỷ lệ tăng trưởng
□ Top-down: Thị phần × Quy mô thị trường
□ Trend: Tăng trưởng lịch sử + điều chỉnh yếu tố thị trường

Dòng sản phẩm/DV | Q1      | Q2      | Q3      | Q4      | Năm
-----------------|---------|---------|---------|---------|-----
[SP/DV 1]        |         |         |         |         |
[SP/DV 2]        |         |         |         |         |
TỔNG DT          |         |         |         |         |
Tăng trưởng YoY  |         |         |         |         |     %

II. DỰ TOÁN CHI PHÍ:
─────────────────────
COGS (Giá vốn hàng bán):
  Nguyên vật liệu: ........%DT
  Nhân công trực tiếp: ....%DT
  Chi phí SX chung: .......%DT
→ Gross Profit Margin mục tiêu: ......%

Chi phí vận hành (OPEX):
  Lương nhân sự: ......tr/tháng × 12 = .........
  Thuê mặt bằng: ......tr/tháng × 12 = .........
  Marketing: .....%DT
  Logistics/vận chuyển: .....%DT
  Khác (điện, nước, văn phòng): .........

III. KẾT QUẢ DỰ KIẾN:
──────────────────────
Doanh thu thuần: ................VND/USD
(-) COGS: .......................VND/USD
(=) Lợi nhuận gộp: .............VND/USD  [Margin: .....%]
(-) OPEX: .......................VND/USD
```

## B. PHÂN TÍCH ĐIỂM HÒA VỐN

```
PHÂN TÍCH BREAK-EVEN (ĐIỂM HÒA VỐN)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CÔNG THỨC:
Chi phí cố định (Fixed Costs) = Lương VP + Thuê mặt bằng + Khấu hao + ...
Biên lợi nhuận đóng góp = Giá bán - Biến phí/đơn vị
Tỷ lệ biên lợi nhuận đóng góp = (Giá bán - Biến phí) / Giá bán

Điểm hòa vốn (đơn vị) = Fixed Costs / (Giá bán - Biến phí/đv)
Điểm hòa vốn (doanh thu) = Fixed Costs / Tỷ lệ biên lợi nhuận đóng góp

VÍ DỤ:
Fixed Costs/tháng = 100 triệu VND
Giá bán = 500.000 VND/sp
Biến phí = 300.000 VND/sp
Biên đóng góp = 200.000 VND/sp (40%)
→ Hòa vốn = 100.000.000 / 200.000 = 500 sản phẩm/tháng
→ Doanh thu hòa vốn = 100.000.000 / 40% = 250 triệu VND/tháng

MARGIN OF SAFETY = (DT thực tế - DT hòa vốn) / DT thực tế × 100%
Mục tiêu: Margin of Safety ≥ 20% để an toàn tài chính
```
