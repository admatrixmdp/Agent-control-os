# Skill: Xây Dựng Loyalty Program & Chương Trình Thành Viên

Bạn là CRM/Loyalty Specialist cho SME Việt Nam.
Mục tiêu là thiết kế chương trình giữ chân khách hàng hấp dẫn, dễ vận hành và sinh lời.

---

## A. KHUNG CHƯƠNG TRÌNH LOYALTY CƠ BẢN

```
CHƯƠNG TRÌNH THÀNH VIÊN [TÊN THƯƠNG HIỆU]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

HỆ THỐNG PHÂN HẠNG (4 bậc điển hình):

┌─────────────┬──────────────┬─────────────────────────────────────┐
│ Hạng        │ Điều kiện    │ Quyền lợi                           │
├─────────────┼──────────────┼─────────────────────────────────────┤
│ 🥉 Đồng    │ Đăng ký KH   │ - Tích 1đ / 10.000đ mua hàng       │
│             │ (0–4.999 đ)  │ - Sinh nhật: voucher [X]%           │
│             │              │ - Miễn phí ship đơn > [X]đ          │
├─────────────┼──────────────┼─────────────────────────────────────┤
│ 🥈 Bạc     │ Mua ≥ 5tr/   │ - Tích 1.5đ / 10.000đ mua hàng     │
│             │ năm          │ - Ưu đãi sinh nhật [X]%             │
│             │              │ - Miễn phí ship mọi đơn             │
│             │              │ - Hỗ trợ ưu tiên (hotline riêng)   │
├─────────────┼──────────────┼─────────────────────────────────────┤
│ 🥇 Vàng    │ Mua ≥ 15tr/  │ - Tích 2đ / 10.000đ mua hàng       │
│             │ năm          │ - Sinh nhật: quà tặng + [X]%        │
│             │              │ - Truy cập sale sớm 24h             │
│             │              │ - Quản lý KH riêng                  │
├─────────────┼──────────────┼─────────────────────────────────────┤
│ 💎 Kim     │ Mua ≥ 30tr/  │ - Tích 3đ / 10.000đ mua hàng       │
│  Cương      │ năm          │ - Trải nghiệm VIP & sự kiện riêng  │
│             │              │ - Hoàn tiền [X]% mọi đơn hàng      │
│             │              │ - Hotline 24/7 ưu tiên tuyệt đối   │

TÍCH ĐIỂM & ĐỔI ĐIỂM:
□ Tỷ lệ tích: [X] đồng mua hàng = 1 điểm (ví dụ: 10.000đ = 1 điểm)
□ Tỷ lệ đổi: 100 điểm = 10.000đ giảm giá (tương đương hoàn 1%)
□ Hạn dùng điểm: 12 tháng kể từ ngày tích
□ Điểm tối thiểu để đổi: 500 điểm
```

## B. QUY TRÌNH VẬN HÀNH LOYALTY

```
QUY TRÌNH ĐĂNG KÝ THÀNH VIÊN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Bước 1: KH đăng ký (website/app/cửa hàng/hotline)
Bước 2: Xác minh thông tin (SĐT/Email OTP)
Bước 3: Cấp mã thành viên + thẻ điện tử
Bước 4: Tặng điểm chào mừng: [X] điểm = [X] nghìn đồng
Bước 5: Gửi email/SMS hướng dẫn sử dụng

QUY TRÌNH TÍCH ĐIỂM
━━━━━━━━━━━━━━━━━━━
Khi mua trực tiếp: Quét thẻ/báo mã thành viên trước khi thanh toán
Khi mua online: Đăng nhập tài khoản → điểm tự động cộng sau 24h
Điểm thưởng thêm: Đánh giá sản phẩm (+[X]đ), Giới thiệu bạn bè (+[X]đ),
                  Sinh nhật (x2 điểm), Sự kiện đặc biệt (x3 điểm)

QUY TRÌNH ĐỔI ĐIỂM
━━━━━━━━━━━━━━━━━━
Kênh đổi: App / Website / Cửa hàng / Hotline
Hình thức:
□ Đổi voucher giảm giá (đổi ngay, áp dụng đơn tiếp theo)
□ Đổi sản phẩm/quà tặng (danh mục đổi điểm riêng)
□ Quyên góp từ thiện (quy đổi ra tiền mặt ủng hộ)
Xác nhận đổi: SMS + Email thông báo

QUY TRÌNH NÂNG/HẠ HẠNG
━━━━━━━━━━━━━━━━━━━━━━
Đánh giá lại hạng: [Hàng tháng/Hàng quý/Hàng năm]
Nâng hạng: Tự động khi đạt ngưỡng chi tiêu
Hạ hạng: Thông báo trước 30 ngày nếu không duy trì ngưỡng
Ân hạn: 3 tháng để đạt lại ngưỡng trước khi hạ hạng
```

## C. LỊCH TRUYỀN THÔNG LOYALTY

```
LỊCH TRUYỀN THÔNG CHƯƠNG TRÌNH THÀNH VIÊN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

HÀNG THÁNG:
□ Ngày 1: Thông báo điểm tháng trước
□ Ngày 5: Nhắc nhở điểm sắp hết hạn (< 30 ngày)
□ Giữa tháng: Flash offer cho thành viên Vàng/Kim cương
□ Cuối tháng: Tổng kết điểm + nhắc đổi điểm

DỊP ĐẶC BIỆT:
□ Sinh nhật KH: Voucher + chúc mừng cá nhân hóa (D-3 trước sinh nhật)
□ Kỷ niệm 1 năm thành viên: Điểm thưởng đặc biệt
□ Lễ Tết: Chương trình điểm x2, x3
□ Flash sale: Ưu đãi sớm 24h cho hạng Vàng+

MẪU SMS CHĂM SÓC:
"[Tên], bạn có [X] điểm tích lũy (~[X]đ).
Điểm sẽ hết hạn vào [Ngày]. Đổi ngay: [Link]"

MẪU EMAIL NÂNG HẠNG:
"Chúc mừng [Tên]! Bạn vừa được nâng lên hạng [Vàng/Kim Cương].
Xem ưu đãi mới của bạn: [Link]"
```
