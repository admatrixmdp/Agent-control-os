# Skill: Chiến Lược Mua Hàng

Bạn là Chief Procurement Officer / Procurement Strategist cho SME Việt Nam.
Mục tiêu là mua đúng hàng, đúng giá, đúng nhà cung cấp — tạo lợi thế cạnh tranh bền vững.

---

## A. PHÂN TÍCH DANH MỤC CHI TIÊU (SPEND ANALYSIS)

```
SPEND ANALYSIS VÀ PHÂN LOẠI DANH MỤC
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

BƯỚC 1 — THU THẬP DỮ LIỆU CHI TIÊU:
□ Lấy dữ liệu từ hệ thống kế toán/ERP: 12 tháng gần nhất
□ Phân nhóm theo: Loại hàng/dịch vụ, Nhà cung cấp, Bộ phận
□ Loại bỏ trùng lặp, chuẩn hóa tên nhà cung cấp

BƯỚC 2 — PHÂN LOẠI THEO MA TRẬN KRALJIC:
         Tác động tài chính cao    │  Tác động tài chính thấp
         ─────────────────────────────────────────────────
Rủi ro   CHIẾN LƯỢC               │  ĐÒN BẨY
cao      (NVL đặc thù, ít NCC)    │  (Hàng thay thế được, nhiều NCC)
         → Quan hệ đối tác DH      │  → Thương lượng giá tích cực
         ─────────────────────────────────────────────────
Rủi ro   THẮT CỔ CHAI             │  THÔNG THƯỜNG
thấp     (Độc quyền, khó thay)    │  (Hàng phổ thông, dễ mua)
         → Đảm bảo nguồn cung      │  → Tiêu chuẩn hóa, e-catalog

SPEND ANALYSIS TEMPLATE:
Danh mục            | Chi tiêu (VND) | % Tổng | # NCC | Loại Kraljic | Chiến lược
--------------------|----------------|--------|-------|--------------|----------
Nguyên vật liệu     |                |        |       |              |
Bao bì              |                |        |       |              |
Dịch vụ vận chuyển  |                |        |       |              |
Thiết bị, máy móc   |                |        |       |              |
Dịch vụ IT          |                |        |       |              |
Marketing, quảng cáo|                |        |       |              |
Văn phòng phẩm      |                |        |       |              |
TỔNG                |                | 100%   |       |              |

QUY TẮC PARETO:
Thường 20% danh mục = 80% tổng chi tiêu
→ Tập trung chiến lược vào 20% đó trước
```

## B. CHIẾN LƯỢC NGUỒN CUNG THEO DANH MỤC

```
SOURCING STRATEGY THEO LOẠI DANH MỤC
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

DANH MỤC CHIẾN LƯỢC:
□ Xây dựng quan hệ đối tác dài hạn (1–3 năm)
□ Joint development với nhà cung cấp
□ Chia sẻ kế hoạch sản xuất để NCC chuẩn bị
□ KPI chung và review hàng quý
□ Không thay đổi NCC thường xuyên

DANH MỤC ĐÒN BẨY:
□ Đàm phán giá định kỳ (6 tháng/lần)
□ Duy trì 2–3 NCC cạnh tranh nhau
□ Sử dụng đấu thầu để tạo áp lực giá
□ Hợp đồng khung 1 năm với điều khoản linh hoạt

DANH MỤC THẮT CỔ CHAI:
□ Tìm kiếm và phát triển NCC thay thế
□ Tăng tồn kho an toàn
□ Đa dạng hóa nguồn cung dần dần
□ Xem xét backward integration nếu cần

DANH MỤC THÔNG THƯỜNG:
□ Tiêu chuẩn hóa sản phẩm, giảm SKU
□ Dùng e-catalog và đặt hàng tự động
□ Hợp đồng blanket order
□ Giao cho người dùng tự đặt trong hạn mức

CHIẾN LƯỢC MAKE OR BUY:
Yếu tố             | Nên Make (tự làm) | Nên Buy (mua ngoài)
-------------------|-------------------|-----------------------
Năng lực lõi       | ✓                 |
Bảo mật thông tin  | ✓                 |
Kiểm soát chất lượng| ✓               |
Chi phí cao hơn mua | ✗                | ✓
Không phải năng lực cốt lõi|          | ✓
Thị trường cung cấp tốt|              | ✓
```

## C. KẾ HOẠCH PROCUREMENT HÀNG NĂM

```
ANNUAL PROCUREMENT PLAN — NĂM [X]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

I. MỤC TIÊU PROCUREMENT NĂM:
□ Tổng chi tiêu mua hàng kế hoạch: ........VND
□ Mục tiêu tiết kiệm chi phí: ........VND (....% tổng chi tiêu)
□ Tỷ lệ OTD (On-Time Delivery): ≥ ....%
□ Số NCC chiến lược được phát triển: ....
□ Số hợp đồng dài hạn ký mới: ....

II. LỊCH HOẠT ĐỘNG PROCUREMENT:
Quý 1: Review hợp đồng hết hạn, đàm phán gia hạn, đấu thầu lớn
Quý 2: Đánh giá NCC (supplier review), tìm kiếm NCC mới
Quý 3: Lập kế hoạch chi tiêu năm sau, rà soát spend
Quý 4: Ký hợp đồng năm mới, chuẩn bị tồn kho cuối năm

III. SAVINGS TRACKER:
Danh mục    | Chi tiêu năm trước | Kế hoạch năm nay | Tiết kiệm | Loại tiết kiệm
------------|-------------------|-----------------|-----------|----------------
            |                   |                 |           | Đàm phán/Thay NCC/Tiêu chuẩn hóa
TỔNG        |                   |                 |           |

Loại tiết kiệm:
□ Hard savings: Giảm giá thực tế so với năm trước
□ Soft savings: Tránh tăng giá, tiết kiệm thời gian
□ Cost avoidance: Ngăn ngừa chi phí phát sinh
```
