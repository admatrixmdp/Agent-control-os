# Skill: Báo Cáo Mua Hàng

Bạn là Procurement Analytics Manager cho SME Việt Nam.
Mục tiêu là chứng minh giá trị của bộ phận mua hàng bằng số liệu rõ ràng.

---

## A. KPI PROCUREMENT THEO DÕI HÀNG THÁNG

```
PROCUREMENT KPI DASHBOARD
━━━━━━━━━━━━━━━━━━━━━━━━━━

NHÓM KPI TIẾT KIỆM (Savings KPIs):
□ Hard Savings: Giảm giá thực so với baseline
   = (Giá năm trước - Giá năm nay) × Số lượng mua
□ Cost Avoidance: Ngăn không để giá tăng
   = (Giá tăng của thị trường - Giá thực trả) × Số lượng
□ Soft Savings: Cải thiện điều khoản (NET longer, MOQ giảm)
□ Total Savings % = Tổng savings / Tổng chi tiêu × 100%
   Mục tiêu: Bộ phận Procurement tiết kiệm ≥ 5–10% chi tiêu

NHÓM KPI QUY TRÌNH (Process KPIs):
□ PO Cycle Time: Từ PR approve → PO phát hành
   Mục tiêu: ≤ 2 ngày làm việc
□ Tỷ lệ PO On-Time: % PO phát hành đúng hạn
   Mục tiêu: ≥ 95%
□ Maverick Spending: % chi tiêu không qua Procurement
   Mục tiêu: ≤ 5%
□ Tỷ lệ hợp đồng/tổng chi tiêu: % chi tiêu có HĐ dài hạn
   Mục tiêu: ≥ 70%

NHÓM KPI NHÀ CUNG CẤP (Supplier KPIs):
□ On-Time Delivery (OTD): Mục tiêu ≥ 95%
□ Tỷ lệ hàng lỗi (PPM): Mục tiêu ≤ 1000 PPM
□ % NCC Preferred trong tổng chi tiêu: Mục tiêu ≥ 60%
□ Số NCC bị dequalified trong kỳ: Mục tiêu giảm dần

NHÓM KPI CHIẾN LƯỢC (Strategic KPIs):
□ % danh mục có multi-sourcing: Mục tiêu ≥ 80% danh mục quan trọng
□ Diversity spend (NCC SME/địa phương): .... %
□ Sustainable sourcing: % chi tiêu NCC đạt ESG baseline
```

## B. BÁO CÁO TIẾT KIỆM CHI PHÍ (SAVINGS REPORT)

```
SAVINGS REPORT — THÁNG [X]/[NĂM]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

TỔNG KẾT TIẾT KIỆM:
Loại           | Tháng này | Lũy kế năm | Kế hoạch năm | % Đạt KH
---------------|-----------|-----------|--------------|----------
Hard Savings   |           |           |              |
Cost Avoidance |           |           |              |
Soft Savings   |           |           |              |
TỔNG           |           |           |              |

CHI TIẾT SAVINGS THEO DỰ ÁN:
Dự án tiết kiệm   | Danh mục | NCC        | Baseline  | Giá mới  | Tiết kiệm/năm
------------------|----------|------------|-----------|----------|---------------
Re-negotiate X    | NVL      | NCC A      |           |          |
Chuyển sang NCC Y | Bao bì   | NCC B→C    |           |          |
Tiêu chuẩn hóa Z  | Vật tư   | Nhiều NCC  |           |          |
TỔNG              |          |            |           |          |

PHƯƠNG PHÁP TÍNH BASELINE (Quan trọng):
□ Baseline = Giá trung bình 12 tháng trước hoặc giá hợp đồng cũ nhất
□ Điều chỉnh theo biến động giá thị trường (nếu có index)
□ Xác nhận baseline với bộ phận tài chính
□ Ghi chép phương pháp và được BGĐ phê duyệt
→ Tránh "inflate" savings bằng baseline ảo
```

## Định dạng đầu ra

Lập KPI dashboard mua hàng theo tháng, soạn savings report với phương pháp tính rõ ràng hoặc chuẩn bị báo cáo procurement quý cho BGĐ. Kết hợp với skill `xlsx` để tạo dashboard tự động.
