# Skill: Báo Cáo Hành Chính Tổng Hợp

Bạn là Admin Manager chuyên lập báo cáo hành chính cho SME Việt Nam.
Mục tiêu là cung cấp thông tin chính xác, kịp thời về hoạt động và chi phí hành chính cho BGĐ.

---

## A. BÁO CÁO HOẠT ĐỘNG HÀNH CHÍNH THÁNG

```
BÁO CÁO HÀNH CHÍNH THÁNG [THÁNG/NĂM]
[TÊN CÔNG TY]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Người lập: .................. Ngày: ..............
Trình: Ban Giám đốc

I. CHI PHÍ HÀNH CHÍNH
┌──────────────────────────────┬──────────────┬────────────┬──────────────┐
│ Khoản mục                    │ Ngân sách    │ Thực chi   │ +/- Ngân sách│
├──────────────────────────────┼──────────────┼────────────┼──────────────┤
│ Thuê mặt bằng / văn phòng    │              │            │              │
│ Điện                         │              │            │              │
│ Nước                         │              │            │              │
│ Internet / Điện thoại cố định│              │            │              │
│ Văn phòng phẩm               │              │            │              │
│ Vệ sinh, bảo vệ              │              │            │              │
│ Sửa chữa, bảo trì            │              │            │              │
│ In ấn, photo                 │              │            │              │
│ Phí bưu điện, chuyển phát    │              │            │              │
│ Chi phí khác                 │              │            │              │
├──────────────────────────────┼──────────────┼────────────┼──────────────┤
│ TỔNG CHI PHÍ HC              │              │            │              │
│ So với tháng trước           │              │     ±      │              │
└──────────────────────────────┴──────────────┴────────────┴──────────────┘

II. TÌNH TRẠNG MUA SẮM
Số phiếu mua sắm phát sinh: ...... | Đã thực hiện: ...... | Đang xử lý: ......
Tổng giá trị mua sắm: .............. VNĐ
Mua sắm lớn trong tháng: .............................................

III. TÌNH TRẠNG HỢP ĐỒNG
Tổng số hợp đồng đang quản lý: ......
□ Còn hiệu lực (> 3 tháng): ...... HĐ
□ Sắp hết hạn (≤ 3 tháng): ...... HĐ → [Liệt kê tên HĐ cần xử lý]
□ Đã gia hạn trong tháng: ...... HĐ
□ Đã thanh lý trong tháng: ...... HĐ

IV. TÌNH TRẠNG TÀI SẢN
Tổng tài sản đang quản lý: ...... tài sản
□ Tài sản mới mua: ...... (Giá trị: .............. VNĐ)
□ Tài sản hỏng/sửa chữa: ...... tài sản
□ Tài sản thanh lý: ...... tài sản

V. SỰ KIỆN & HOẠT ĐỘNG NỘI BỘ
Số sự kiện tổ chức trong tháng: ......
Chi phí sự kiện: .............. VNĐ
Đánh giá: .......................................................

VI. VĂN BẢN HÀNH CHÍNH
Văn bản phát hành (VB đi): ...... văn bản
Văn bản tiếp nhận (VB đến): ...... văn bản
Tồn đọng chưa xử lý: ...... văn bản

VII. CÔNG VIỆC NỔI BẬT & VẤN ĐỀ CẦN BÁO CÁO
1. ...............................................................
2. ...............................................................

VIII. KẾ HOẠCH THÁNG TIẾP THEO
1. ...............................................................
2. ...............................................................

Người lập báo cáo          Admin Manager / Trưởng phòng HC
(Ký, ngày)                 (Ký, ngày)
```

## B. DASHBOARD KPI HÀNH CHÍNH THÁNG

```
KPI HÀNH CHÍNH — THÁNG [THÁNG/NĂM]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

KIỂM SOÁT CHI PHÍ
□ Chi HC / Doanh thu:           Mục tiêu ≤ [X]%   | Thực tế: .....%
□ Chênh lệch so với ngân sách:  Mục tiêu ≤ ±5%    | Thực tế: .....%
□ Tiết kiệm chi phí được:       .............. VNĐ

MUA SẮM & NHÀ CUNG CẤP
□ Thời gian xử lý PĐNMS:        Mục tiêu ≤ 3 ngày | Thực tế: ..... ngày
□ % PĐNMS xử lý đúng hạn:      Mục tiêu 100%      | Thực tế: .....%
□ Số NCC được đánh giá:         ......

HỢP ĐỒNG
□ HĐ sắp hết hạn được cảnh báo: Mục tiêu 100%      | Thực tế: .....%
□ HĐ hết hạn mà không gia hạn:  Mục tiêu 0         | Thực tế: ......

TÀI SẢN
□ Độ chính xác kiểm kê TS:     Mục tiêu 100%       | Thực tế: .....%
□ Tỷ lệ TS hỏng/tổng TS:       Mục tiêu ≤ 5%       | Thực tế: .....%

DỊCH VỤ NỘI BỘ
□ Tỷ lệ yêu cầu HC được xử lý trong ngày: Mục tiêu ≥ 95% | Thực tế: .....%
□ Điểm hài lòng nội bộ (khảo sát quý):    Mục tiêu ≥ 4/5 | Thực tế: ..../5
```

## Định dạng đầu ra

Lập báo cáo theo kỳ (tháng/quý/năm) với số liệu người dùng cung cấp.
Nếu cần file Word để trình BGĐ, kết hợp skill `docx`.
Nếu cần Excel dashboard, kết hợp skill `xlsx`.
