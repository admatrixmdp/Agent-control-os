### 1.2 Setup Zalo OA (Step-by-step)

```
STEP 1: Create Zalo Business Account
├─ Go to: https://official.zalo.me
├─ Login with Zalo personal account
├─ Click "Tạo OA mới"
│  ├─ Enter business name (Shop name)
│  ├─ Choose category (Retail/Fashion/Food)
│  ├─ Upload avatar (Shop logo, 1:1 ratio, tối thiểu 200x200px)
│  ├─ Write description (2-3 dòng about shop)
│  └─ Agree terms
│
├─ Wait for approval (24-48 hours)
└─ OA is live!

STEP 2: Verify OA (Important!)
├─ Why verify: Get "✓ Xác minh" badge
│  ├─ Higher trust from customers
│  ├─ Better algorithm ranking
│  ├─ Can broadcast without restrictions
│  └─ Professional positioning
│
├─ Go to Settings > Xác minh OA
├─ Upload documents:
│  ├─ GPKD (Giấy phép kinh doanh) / CNTT (Chứng nhận thành lập)
│  ├─ Hóa đơn điện/nước (Proof of business address, dated < 3 months)
│  ├─ Ảnh chân dung chủ OA (Personal photo, clear face)
│  └─ Authorization letter (If not owner, từ chủ ủy quyền)
│
├─ Submit & wait 3-5 days
└─ Badge appears = Verified! ✓

STEP 3: Setup OA Branding
├─ Avatar: Logo 200x200px (High quality)
├─ Cover image: 1200x627px (Banner image, shop aesthetic)
├─ Description: "Chào mừng đến [Shop]. Bán [loại hàng]. FREE SHIP [điều kiện]"
├─ Links:
│  ├─ Website URL (If have)
│  ├─ Shopee link
│  ├─ Lazada link
│  └─ TikTok Shop link (If have)
│
├─ Contact info:
│  ├─ Phone number
│  ├─ Email
│  └─ Address (Business location)
│
└─ Save & Review (Looks professional?)

STEP 4: Enable Features
├─ Chat: ON (Default, allow customer message)
├─ Broadcast: ON (Send promotions)
├─ OA page: ON (Public profile, like Facebook)
├─ Zalo Pixel: Install (Tracking)
├─ Auto-reply: Setup (Message when offline)
└─ Menu: Setup (See section 1.3)

Time needed: 2-3 hours (Including documentation wait)
Cost: FREE
```

## 2. Zalo Ads (Quảng Cáo Zalo)

### 2.1 Ad Formats & Best Practices

**Available formats:**

```
1. BANNER ADS (Static image, display at top)
   ├─ Size: 1200x627px
   ├─ File: JPG/PNG < 100KB
   ├─ Placements: News feed
   ├─ CPC: 500-1500đ
   ├─ Best for: Brand awareness, broad audience
   ├─ CTR: 0.5-1.5%
   └─ Example: [Logo + headline + CTA button]

2. ARTICLE ADS (Rich content, carousel)
   ├─ Title: 50 chars max
   ├─ Description: 100 chars max
   ├─ Images: 3-10 images, 1200x627px each
   ├─ CPC: 800-2000đ
   ├─ Best for: Product showcases, stories
   ├─ CTR: 1-2.5%
   └─ Conversion: Better than banner (More info)

3. VIDEO ADS (15-120 seconds)
   ├─ Format: MP4, WebM, MOV (< 500MB)
   ├─ Aspect ratio: 1:1, 16:9, 9:16
   ├─ CPC: 1000-3000đ
   ├─ Best for: Demo, testimonial, emotion
   ├─ CTR: 2-4% (Higher than image!)
   ├─ VTR (Video view rate): 30-60%
   └─ ROI: Best if message clear in first 3s

4. MULTI-PRODUCT ADS (Showcase 2-6 products)
   ├─ Similar to carousel on Facebook
   ├─ Each product: Image + price + name
   ├─ CPC: 1200-2500đ
   ├─ Best for: Shopping, upsell, bundling
   ├─ Conversion: High (Product details visible)
   └─ Example: [Product 1] [Product 2] [Product 3] [Product 4]
```

### 2.2 Campaign Objectives & Targeting

**Campaign objectives:**

```
1. AWARENESS (Brand recognition)
   ├─ Optimize for: Impressions (CPM pricing)
   ├─ CPM: 20-80K per 1000 impressions
   ├─ Best for: New product launch, brand building
   ├─ Metric: Impressions, reach, frequency
   └─ Not good for: Immediate sales

2. TRAFFIC (Drive to website/app)
   ├─ Optimize for: Link clicks (CPC pricing)
   ├─ CPC: 500-2000đ
   ├─ Best for: Landing page, conversions
   ├─ Metric: Click-through rate, cost per click
   └─ Good for: Website traffic + conversions

3. FOLLOWERS (Grow OA followers)
   ├─ Optimize for: OA followers (CPF pricing)
   ├─ CPF: 1000-5000đ per follower
   ├─ Best for: Building audience, retention
   ├─ Metric: New followers, total followers
   └─ Long-term: Follower list = Free messaging channel

4. MESSAGES (Zalo chat messages)
   ├─ Optimize for: Conversations (CPC pricing)
   ├─ CPC: 1000-3000đ
   ├─ Best for: Lead generation, customer engagement
   ├─ Metric: Conversations, conversation rate
   └─ Good for: B2B inquiry, consultations

5. CONVERSIONS (Purchases/actions on website)
   ├─ Optimize for: Conversions (CPA-like)
   ├─ Cost: Variable (Depends on pixel setup)
   ├─ Best for: Direct sales, e-commerce
   ├─ Metric: Conversion, ROAS
   ├─ Requirement: Zalo Pixel installed
   └─ Most sophisticated targeting
```

**Targeting options:**

```
Demographics:
├─ Age: 18-65+ (Choose range)
├─ Gender: Male / Female / Both
├─ Location: VN regions / Provinces / Cities
│  └─ Best practice: TP HCM, Hà Nội (Highest CAC but good revenue)
│  └─ Secondary: Đà Nẵng, Hải Phòng (Lower CAC)
│
Interests & Behaviors:
├─ Interest categories: Phụ nữ, thời trang, lifestyle, etc
├─ Device: Android / iOS / Both
├─ Language: Vietnamese
│
Lookalike audience (Advanced):
├─ Upload customer list (Email, phone, MSISDN)
├─ Zalo creates "similar user" segment
├─ High conversion potential
│
Custom audience (Retargeting):
├─ People who visited your website (Zalo Pixel)
├─ People who engaged with your ads before
├─ People in your email list

Example targeting for fashion shop:
├─ Age: 20-55
├─ Gender: Female (Primarily)
├─ Location: TP HCM, Hà Nội, Hải Phòng, Đà Nẵng
├─ Interest: Fashion, lifestyle, shopping
├─ Device: Primarily iOS/Android (85% via mobile)
└─ Retargeting: Website visitors (Pixel)
```

### 2.3 Budget Optimization & ROAS

```
Daily budget structure:
├─ Small test: 100K-200K/day (Test 1-2 weeks)
├─ Scale: 500K-1M/day (Once proven)
├─ Mature: 1-5M/day (Established ad accounts)
└─ VIP: 5M+/day (For profitable campaigns)

Zalo Ads performance benchmarks (VN TMĐT):

Campaign | Objective | CPM | CPC | CTR | CPA | ROAS |
|---|---|---|---|---|---|---|
Awareness | Impressions | 35K | - | 0.8% | - | N/A |
Traffic | Link clicks | - | 800 | 1.2% | - | 2-3:1 |
Followers | OA follow | - | - | 0.9% | 2.5K | N/A |
Messages | Chat | - | 1500 | 1.8% | 1500 | 3-4:1 |
Conversions | Purchase | - | 1200 | 1.5% | 400K | 3-6:1 |

ROAS calculation:
├─ Revenue from ad: 10M (Orders from this campaign)
├─ Ad spend: 2.5M
├─ ROAS = 10M / 2.5M = 4:1 ✅ (Great!)
│  └─ Benchmark: 3:1 = break-even with normal margin
│  └─ 5:1+ = very profitable
│
└─ Break-even COGS:
   ├─ If COGS = 40% of price
   ├─ ROAS 3:1 means: Gross profit covers ads + ops
   ├─ ROAS 5:1 means: Lots of room for profit
```

### 2.4 Zalo Pixel (Tracking & Retargeting)

**Purpose:** Track conversions, build retargeting lists

```
Setup:
├─ Go to Zalo Ad Manager > Pixels
├─ Create new pixel
├─ Copy pixel code: <script>...</script>
├─ Paste in website <head> tag (Or via Google Tag Manager)
├─ Test: Install browser extension "Zalo Analytics"
│  └─ Verify pixel fires when visiting site
│
Tracked events:
├─ PageView: Every page load
├─ ViewContent: Product page view
├─ AddToCart: Add to cart
├─ Purchase: Successful checkout
├─ Lead: Form submission
├─ CompleteRegistration: Sign up

Using pixel data:
├─ Retargeting: Show ads to people who visited
├─ Lookalike: Find similar people to converters
├─ Optimization: Algorithm learns what to optimize for
└─ Measurement: Track ROAS accurately

Retargeting example:
├─ List A: Visited website 1-7 days ago (Show conversion ads)
├─ List B: Viewed product but not purchase (Show discounts)
├─ List C: Cart abandoners (Show reminders)
├─ List D: Past purchasers (Upsell/cross-sell)
└─ Results: Retargeting ROAS often 5-10x better than cold audience!
```

### 2.5 Campaign Performance & Optimization

```
Weekly optimization checklist:

Monday morning:
├─ Review last week's performance
├─ Check ROAS vs target (Target: 3.5:1)
├─ Identify top/bottom performers
│  ├─ Top ad: Scale (Increase budget 20%)
│  ├─ Bottom ad: Pause or optimize
│  └─ Medium: Keep testing
│
├─ Check CTR (Target: 1-2%)
│  ├─ Low CTR < 0.8%: Check creative, targeting
│  └─ High CTR > 2%: Might be misleading, check conversions
│
├─ Check CPA (Cost per acquisition)
│  ├─ CPA > 50% of AOV: Not profitable
│  ├─ CPA 30-50% of AOV: OK
│  ├─ CPA < 30% of AOV: Great!
│
└─ Actions:
   ├─ Pause underperforming creatives
   ├─ Test new audience segments
   ├─ Adjust bid (If need cheaper traffic)
   └─ Implement learnings in next week
```

## 3. Zalo Mini App (Advanced)

### 3.1 When to Use Mini App

```
Mini App is:
├─ Lightweight app within Zalo
├─ Can be accessed directly from chat
├─ Faster than website, simpler than full app
├─ Stores data, personalization

Use Mini App when:
✅ Have Shopee/Lazada shop (Low priority, already have platform)
✅ Medium+ shop (500+ orders/month) - justify dev cost
✅ Want better mobile experience than website
✅ Need in-app features (Loyalty, subscription)
✅ Want Zalo chat integration (Chat while shopping)

DON'T use Mini App if:
❌ Small shop (< 500 orders/month) - ROI not there
❌ Just starting out (Build website first)
❌ Limited budget for development

Features possible:
├─ Product catalog (Browse, filter)
├─ Shopping cart (Add, remove, modify)
├─ Checkout (Payment integration)
├─ Loyalty program (Earn points)
├─ Order tracking (Track package)
├─ Chat with shop (Direct from app)
└─ Notifications (Order updates)
```

### 3.2 Mini App Development

```
Development options:

1. Zalo Mini App Store (Official)
   ├─ Official templates available
   ├─ Cost: Free to expensive (Depending on features)
   ├─ Time: 2-8 weeks
   ├─ Hosting: Zalo handles
   └─ Best for: Medium shops with budget

2. Third-party providers (VN)
   ├─ Companies: Pancake, Haravan, Subiz
   ├─ Cost: 5M-20M setup + monthly fee
   ├─ Time: 1-4 weeks (Pre-built templates)
   ├─ Integration: With Shopee/Lazada
   └─ Best for: Quick deployment

3. Custom development (Agencies)
   ├─ Cost: 20M-100M+ (Depends on complexity)
   ├─ Time: 4-12 weeks
   ├─ Result: Fully customized
   └─ Best for: Large shops with specific needs

My recommendation:
├─ Start: Website + Zalo OA (Free/cheap)
├─ Scale: Consider Mini App once revenue > 100M/month
└─ This justifies dev cost
```

## 4. Zalo Community (Groups)

### 4.1 Creating & Managing Zalo Groups

**Purpose:**
- Direct relationship with customers (Not owned by platform)
- Exclusive offers for members
- Community building, brand loyalty
- Word-of-mouth marketing

```
Zalo Group setup:

Step 1: Create group
├─ Open Zalo app
├─ Tap "+" > "Tạo nhóm"
├─ Name: [Shop name] + "Members" or "Community"
│  └─ Example: "PANG Members Exclusive"
├─ Add profile picture (Shop logo)
├─ Initial members: Start with existing customers
│  └─ Invite from Zalo contacts, get permission first
│
├─ Group settings:
│  ├─ Privacy: Private (Members only)
│  ├─ Admin approval: ON (Control who joins)
│  ├─ Pinned announcements: ON (Sticky posts)
│  └─ Post moderation: OFF (Trust members, moderate bad behavior)
│
└─ Group size: Aim for 500-5000 (Engage-able size)
   ├─ Too small (< 100): Dead
   ├─ Too large (> 10K): Can't manage

Step 2: Create group rules
Pinned announcement:
"Chào mừng đến PANG Members! 👋
Nhóm này dành cho khách hàng loyal của PANG.

✅ ĐƯỢC PHÉP:
├─ Chia sẻ review/feedback

❌ KHÔNG ĐƯỢC PHÉP:
├─ Spam, quảng cáo ngoài (Affiliate không được)
├─ Nội dung xấu, bôi nhọc
├─ Bán hàng, khác shop
└─ Xin follow, tương tác ảo

🎁 LỢI ỨC MEMBERS:
├─ Exclusive deals 10-15% extra

└─ Birthday gift vouchers

Step 3: Growth strategy
├─ Invite happy customers (Great reviews)

├─ Email: "Access exclusive deals - join group"
```

### 4.3 Group Monetization (Without Being Salesy)

```
WHAT TO DO ✅:
├─ Exclusive member discounts (10-15% extra)

├─ LTV: 4-5x higher (Long-term value)
├─ Cost to maintain: 5-10 hours/week (Cheap!)
└─ ROI: Very high if managed right

Example calculation:
├─ Group 1000 members
├─ 120 orders/month from group
├─ AOV 1.2M (vs regular 1M)
├─ Revenue: 120 × 1.2M = 144M/month
├─ Time cost: 8h × 50K/h = 400K
├─ Profit: 144M - [COGS, platform fee, etc] minus 400K
└─ ROI: Huge!
```

## 5. Zalo B2B (Cho Bán Sỉ)

### 5.1 B2B Use Cases

```
When to use Zalo for B2B:

Perfect for:
├─ Dropshippers (Will contact you on Zalo, not email)
├─ Resellers (Small shop owners, prefer Zalo)
├─ Wholesalers (Negotiate bulk prices)
├─ Agency partnerships (Influencer/blogger outreach)
└─ Supplier relationships (Factory level)

Why Zalo works for B2B:
├─ Professional but personal (Not as stiff as email)
├─ Real-time chat (Faster negotiation)
├─ Can share samples (Via Zalo photos)
├─ Payment flexible (Phone transfer, not strict)
├─ Relationship building (Personal touch)

Stats:
├─ 75% of VN shop owners actively use Zalo
├─ B2B inquiries on Zalo: 60% (vs 25% Facebook)
├─ Conversion rate: B2B lead → Order on Zalo = 35% (High!)
└─ This is serious business, not random chat
```

### 5.2 B2B OA Strategy

```
B2B-specific OA elements:

Menu should include:
├─ 🛍️ Sản phẩm sỉ (Wholesale pricing list)
├─ 📋 Bảng giá (Price table, minimum quantities)
├─ 📦 Mẫu hàng (Order samples, testing)
├─ 💼 Đối tác (Become partner, reseller program)
└─ 📞 Liên hệ B2B (Direct to B2B manager)

Content strategy (Different from B2C):
├─ Product info: Detailed (Specs, material, care)
├─ Pricing: Transparent (Tier by quantity)
├─ Lead time: Honest (Production time, shipping)
├─ MOQ: Clear (Minimum order quantity)
├─ Payment terms: Flexible (30-60 days, some cases)

Example conversation:
```
