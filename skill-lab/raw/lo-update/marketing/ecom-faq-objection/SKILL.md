# FAQ & Xử Lý Objection Cho Thương Mại Điện Tử

## 1. Tại Sao FAQ & Objection Handling Quan Trọng

80% khách chùa có 1 objection trước khi mua. Objection là friction point. Nếu friction quá cao → khách leave, không mua.

FAQ + objection handling = reduce friction, increase conversion.

Data: E-commerce với good FAQ page = 20-30% conversion lift.

Khách hàng journey: Interested → Question → Objection → Resolution → Purchase

Nếu bạn answer FAQ trước khách hỏi = smooth journey = higher conversion.

## 2. 20 Objection Phổ Biến TMĐT VN (+ Xử Lý)

### Objection 1: Giá Cao
**Khách nói:** "Giá 499k quá mắc. Áo bình thường 100k thôi."

**Root cause:** Khách không hiểu value vs cost.

**Framework xử lý:**
- Acknowledge: "Tôi hiểu giá cao. Nhưng..."
- Reframe: "Áo này dùng được 3 năm, áo bình thường dùng 3 tháng. Per-month cost lại rẻ hơn."
- Evidence: "100 khách mua 1 lần, quay lại mua thêm 3 lần vì quality."
- CTA: "Nếu still không sure, try size S first?"

**FAQ answer:**
"Q: Tại sao giá 499k?
A: Vải 100% organic cotton dari Peru, rang thủ công, dệt trên 1000 công đoạn. So với fast fashion:
- Fast fashion: 100k, dùng 3-4 tháng → per month 25-33k
- Áo chúng tôi: 499k, dùng 3 năm = per month 13.8k
+ Áo tôi không xù, không chua, vẫn mềm.
= Lẻ lời so với áo bình thường 😊"

### Objection 2: Sợ Hàng Fake
**Khách nói:** "Online bao giờ cũng fake. Bạn hàng chính hãng không?"

**Root cause:** Trust issue. Khách từng bị scam.

**Framework:**
- Acknowledge: "Tôi hiểu lo. Online có hàng giả."
- Evidence: "Chúng tôi bán trực tiếp từ nhà sản xuất. No middleman. Certificate authentic sẽ đi kèm."
- Social proof: "5 năm hoạt động, 10k khách, 0 complaint fake."
- Guarantee: "Nếu fake, return 100%, khôn hỏi."

**FAQ:**
"Q: Sản phẩm này chính hãng không?
A: 100% chính hãng. Lý do:
- Chúng tôi là nhà sản xuất (direct to consumer)
- Không qua middleman
- Certificate chứng thực đi kèm mỗi sản phẩm
- Nếu fake, guarantee return 100%, no question

Hoặc verify: [Link verify page]"

## 3. FAQ Framework: Acknowledge → Reframe → Evidence → CTA

Setiap FAQ answer follow struktur:

### ACKNOWLEDGE (20%)
Terima kasih pertanyaan. Validasi feeling.
"Pertanyaan baik. Banyak customer tanya ini."

### REFRAME (30%)
Ubah perspective. Show benefit.
"Sebenarnya ini adalah strength kami, bukan weakness."

### EVIDENCE (40%)
Data, proof, testimonial.
"5000 customer try, 98% satisfied."

### CTA (10%)
Soft call to action, next step.
"Chat kami nếu question lebih lanjut. Kami siap!"

## 9. FAQ SEO Schema Markup

Google can extract FAQ and show in search result.

**Format:**
```
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "Berapa harganya?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Harga 499k per item..."
      }
    }
  ]
}
</script>
```

**Benefit:**
- Google show FAQ in search result
- More visibility
- Click-through rate ↑
- Rank better for Q&A queries

**Implementation:**
- Use Yoast SEO plugin (auto generate)
- Or manually add to website
- Test: Google Rich Result Tester
