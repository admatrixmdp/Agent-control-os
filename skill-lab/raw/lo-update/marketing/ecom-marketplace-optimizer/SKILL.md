### 1.1. Shop Decoration (Trang trí gian hàng)

**1. Shop Banner (Ảnh bìa shop)**
- Kích thước: 1200 × 400px (chuẩn Shopee)
- Content:
  - Logo brand (góc trái)
  - Slogan/tagline chính (giữa)
  - CTA: "Free shipping" / "Best seller" / "Quality guaranteed" (góc phải)
- Design tip: Vibrant color, clear font, simple layout (khách mobile dễ đọc)

**Example banner:**
```

│ [Logo]                         │
│          Welcome to XYZ Brand  │
│          Free Shipping 50K+    │
│                    🎁 Genuine  │

```

**2. Shop Category (Phân loại sản phẩm)**
- Tạo 5-8 categories (không quá nhiều, khách confused)

  - Skincare (toner, serum, cream)
  - Makeup (foundation, lipstick, eyeshadow)
  - Body Care (lotion, soap)
  - Tools (brush, sponge)
  - Sets (bundle offers)

**3. Shop Collections (Nhóm sản phẩm)**
- Create trending collections:
  - "New arrival" (thêm hàng mới)
  - "Best seller" (bán chạy nhất)
  - "On sale" (giảm giá)

- Bao gồm:

### 1.2. Shop Score & Rating Improvement

**Shop Score = tổng của 3 chỉ số:**

| Chỉ số | Trọng số | Target | Cách tăng |
|--------|---------|--------|-----------|
| **Shop rating** | 50% | 4.8+ | Deliver on time, good quality, respond fast |
| **Ship on time** | 25% | >99% | Set realistic delivery time, ship early |
| **Chat response** | 25% | >90% | Reply <5 min, set auto-reply rules |

**Công thức:**
```
Shop Score = (Rating × 50%) + (On-time rate × 25%) + (Chat response × 25%)

Example:
- Rating: 4.7/5 = 94%
- Ship on time: 99%
- Chat response: 95%
Score: (94% × 0.5) + (99% × 0.25) + (95% × 0.25) = 95.75% ✓ Excellent
```

**Cách tăng Shop Rating (4.8+):**

1. **Delivery:**
   - Set delivery time slightly higher (not 1-2 days, say 2-3 days)
   - Ship ASAP, often arrive early
   - Shopee reward early delivery with algorithm boost

2. **Product Quality:**
   - Source good suppliers
   - QC mỗi order trước ship
   - Accept returns gracefully

3. **Packaging:**
   - Nice packaging (2-3 riêng layers)
   - Add thank you card / small gift
   - Unboxing experience matters (photo on Shopee)

4. **Communication:**
   - Answer product questions within 2 hours
   - Send tracking info immediately
   - Follow-up after delivery: "Happy with product?"

**Cách tăng Ship on time rate (>99%):**

```
Day 1: Order received
- Review order immediately (5 min)
- Check inventory
- QC product
- Pack product
- Create shipping label
- Send to Shopee logistics
Total: <2 hours

Shopee expects:
- Confirm order: <2 hours
- Ship: <1 day
- Estimate 99%+ on-time
```

**Cách tăng Chat Response rate (>90%):**

- Set business hours: 6AM - 11PM (avoid night complaints)
- Enable auto-reply:
  ```
  "Thanks for contacting us!
  We'll respond in <5 minutes (business hours).
  Weekdays 6AM-11PM.
  For urgent: Zalo [number]"
  ```
- Use Shopee's auto-response templates
- Hire 1 customer service staff if order >50/day

**Monitor Dashboard:**
- Settings → Shop statistics → View daily/weekly score
- Identify drops: Is it rating? Delivery? Response?
- Fix specific issue

### 1.3. Shopee Mall vs Regular Seller Strategy

**Shopee Mall:**
- Official Shopee program for vetted sellers
- Benefits:
  - Prime badge on product (trust signal)
  - Mall discount (customers expect cheaper)
  - Higher search ranking
  - Dedicated customer support
- Requirements:
  - Shop rating: 4.6+
  - Seller registration fee: 500K-2M (tùy category)
  - Product original/chính hãng (no fake brands)
  - Monthly sales: usually 5M+ recommended

**Decision matrix:**

| Factor | Regular seller | Shopee mall |
|--------|---|---|
| **Setup cost** | 0 | 500K-2M |
| **Monthly fee** | 0 | 200-500K |
| **Ranking boost** | Low | High |
| **Customer trust** | Medium | High |
| **Discount pressure** | Low | Medium |
| **Best for** | New, niche | Established, volume |

**Recommendation:**
```
<1M/month GMV → Regular seller focus on
1-5M/month GMV → Prepare for Mall application
>5M/month GMV → Join Shopee Mall (ROI positive)
```

**Mall Strategy if you join:**
- Competitor pricing: Must be 5-10% cheaper than regular seller
- Promotion: Use vouchers to stay profitable
- Volume: Focus volume (higher turnover = lower margin acceptable)

### 1.4. Shopee Ads: Search Ads, Discovery, Boost

**Shopee Ads 101:**

**Type 1: Search Ads (Quảng cáo tìm kiếm)**
- Hiển thị khi khách search keyword
- Cost: Per click (CPC)
- Placement: Top search results (spot 1-3)
- Best for: High-intent buyers (searching exact product)

**Setup:**
```
1. Shop → Shopee Ads → Create campaign
2. Name: "[Product name] - Search"
3. Budget: 50,000/day (adjust based on volume)
4. Bid: Start 500đ/click, optimize up/down
5. Keyword: Select 5-10 main keywords
   Example: "serum dưỡng da", "vitamin c serum", "serum trắng da"
6. Daily budget cap: 50K (to avoid overspend)
```

**Optimization:**
```
Week 1: Bid high (1000đ), monitor CTR/conversion
Week 2: Identify best keywords, reduce bid on low performers
Week 3: Scale best keywords (increase daily budget to 100K)
Week 4: Cut worst keywords completely

Metric to watch:
- CTR: >5% good, <2% bad (pause keyword)
- Conversion rate: >3% good
- Cost per sale: < (Product margin / 2) to be profitable
```

**Example:**
```
Product: Vitamin C serum, price 300K, COGS 100K
Margin: 200K per unit = 67%

Cost per sale target: <100K (to maintain 50% margin after ad cost)
Conversion rate: 3% (50 clicks = 1-2 sales)
Cost per click: 2000đ
Cost per sale: 2000đ × 50 clicks / 2 sales = 50,000đ ✓ Profitable!
```

**Type 2: Discovery Ads**
- Hiển thị trong Shopee feed (Shopee home, recommendations)
- CPM-based (cost per 1000 impressions)
- Best for: Brand awareness, retargeting

**Setup:**
```
1. Ads → Discovery ads
2. Budget: 100K/day
3. Audience: All users (hoặc custom lookalike)
4. Creative: 1-3 product images + copy
5. Bid: Start 20K per 1000 views (optimize later)
```

**Type 3: Boost (Nâng hạng sản phẩm)**
- Pay flat fee to boost 1 product up the ranking
- Cost: 20K - 500K (tùy how long, how high)
- Duration: 1-7 days

**When to use:**
- Launching new product (need visibility)
- Flash sale (need traffic boost)
- Inventory clearing (quick revenue)

### 1.6. Shopee Live Strategy

**Shopee Live = Real-time selling on Shopee**
- Watch time: 30-120 minutes
- Expected sales: 10-100 units per live (tùy product & audience)
- Higher conversion: 5-15% (vs 2-3% normal)

**Setup:**
```
1. Shop → Shopee Live → Schedule live
2. Time: Pick 1-2 time slots (consistent, e.g., 7 PM daily)
3. Product: Select 3-5 products (not too many)
4. Promotion: Live-exclusive discount (e.g., 20% off)
5. Duration: 60-90 min (sweet spot)
```

**Live selling tips:**

1. **Pre-live (15 min before):**
   - Test camera, mic, internet (critical!)
   - Set up products (have samples ready)
   - Create teasers on feed ("Live in 15 min!")
   - Prepare talking points

2. **During live:**
   - Greet viewers: "Hi friends, welcome!"
   - Show products clearly (good lighting, close-ups)
   - Explain benefits (not features)
   - Discount urgency: "Only 50 units at this price"
   - Q&A: Answer comments in real-time
   - Demo: Let audience see product in action
   - Call to action: "Add to cart now!"

3. **Live selling psychology:**
   - FOMO (Fear of Missing Out): Limited quantity
   - Social proof: "50 already sold in 5 minutes!"
   - Urgency: "Discount ends in 10 minutes"
   - Exclusivity: "Live-only deals"

**Example live flow (60 min):**
```
0-5 min: Welcome & intro (let audience gather)
5-15 min: Product 1 demo & sell (target: 30 units)
15-25 min: Q&A + Product 2
25-35 min: Product 2 demo & sell (target: 20 units)
35-45 min: Best seller showcase + testimonials
45-55 min: Flash bundle (3 products together, heavy discount)
55-60 min: Final call to action, thank you, goodbye
```

**Expected metrics:**
```
Viewers: 2,000-5,000 (if 1000 followers)
Watch time: 80,000-120,000 minutes (avg 40-60 min per viewer)
Comments: 500-1,000
Sales: 20-50 units (conversion 1-2%)
Revenue: 6M-15M (typical)
```

### 1.7. Voucher Strategy

**Types of Shopee Vouchers:**

**1. Shop voucher (Do shop cấp)**
- Direct discount: "10% off, max 50K"
- Best for: High-value products
- Usage: Create 5-10 voucher templates
- Strategy:
  ```
  Tiered vouchers:
  - 50K+: 5% off (not attractive)
  - 100K+: 10% off (moderate)
  - 200K+: 15% off (attractive, margin hit)
  - 500K+: 20% off (bundle, acceptable)
  ```

**2. Follow voucher (Theo dõi shop để nhận)**
- Free (0 cost) voucher for followers
- Incentivize shop follow: "Follow → 10K off"
- Usage: Create weekly, rotate

**3. Add-on deal (Buy X, get Y discount)**
- E.g., "Buy serum, add lotion for 50% off"
- Push complementary products
- Increase AOV (average order value)

**4. Flash sale voucher**
- Used with Shopee Flash Sale feature
- Shopee picks best products, heavy discount
- Constraint: Max 50% discount (Shopee rule)
- Best for: Clearing inventory, volume

**Voucher calendar example:**

```
Week 1:
- Mon: New customer 10K discount
- Wed: Flash sale on top 3 products
- Fri: Bundle voucher (buy 2, 20% total)
- Sun: Loyalty voucher (for repeat customers)

Week 2: Repeat, different vouchers
```

**Profitability check:**
```
Product: Serum, Price 300K, COGS 100K, Margin 200K (67%)

Voucher: 10% off = 30K discount
New price: 270K
New margin: 170K per unit (56% margin) ✓ Still profitable

But if 10% → 20% (60K discount):
New price: 240K
New margin: 140K (47% margin) → Borderline, only if volume scales 2x
```

### 1.8. Free Shipping Optimization

**Shopee Free Shipping Program:**
- Show "Free shipping" badge on products
- Builds trust (customers don't fear surprise fees)
- Algorithm boost: Shopee promotes free shipping products

**How to offer free shipping:**

**Option 1: Direct absorption**
```
Product price: 300K
Shipping cost: 15K-30K
You absorb: Sell at 300K, pay shipping, net profit = 155K (vs 200K)
Cost: 30-45K per order (sacrifice margin)
```

**Option 2: Price-inclusive**
```
Price without free shipping: 270K
Add shipping buffer: +30K
Final price: 300K (same!)
But now offer "Free shipping"
Customer happy (sees "Free shipping" badge)
You break even on shipping

Problem: Competitor selling 270K without free shipping
You're now higher priced → lose to competitor
```

**Option 3: Mixed (Recommended)**
```
Products <100K: Shipping cost too high, customer pays for shipping
Products 100K-300K: You absorb shipping cost (offer free shipping)
Products >300K: Free shipping (obvious)

This way:
- Budget products: Buyer expects to pay shipping
- Mid-range: Buyers see free shipping as win
- Premium: Expected benefit
```

**Free shipping impact:**
- Products with free shipping: 30-50% higher click rate
- Products with free shipping: 15-25% higher conversion
- Trade-off: Lower per-unit margin, but volume compensates

**Decision: Shopee Mall vs LazMall?**
```
Shopee:
- More competitive
- Customers more active
- Harder to qualify

Lazada:
- Less competitive
- Customers less active but willing to spend
- Easier to qualify

Strategy:
- If you're new: Start with Lazada (easier)
- If you're established: Shopee + Lazada both
- If you must choose 1: Shopee (bigger market)

### 2.4. Flash Sale Participation

**Lazada Flash Sale = Daily 16:00 / Weekly / Mega Campaign**

- Every day at 4 PM, 2-hour duration
- Apply products with 20-50% discount
- High traffic, good for volume

**Weekly sale (e.g., Wednesday):**
- Specific theme (e.g., tech Wednesday)
- 24-hour duration
- Higher discount allowed (30-60%)

**Mega Campaign (1x/month):**
- National event (like Black Friday)
- Heavy traffic, huge discounts
- Inventory clear-out opportunity

**Strategy:**
```
Daily sales: Include 2-3 top sellers (low discount, 10-15%)
- Goal: Volume + visibility
- Inventory: Stock up 50+ units

Weekly sales: Include 5-10 bestsellers (medium discount, 20-30%)
- Goal: Higher traffic, clear inventory
- Inventory: Stock up 100+ units

Mega sale: All stock (heavy discount, 30-50%)
- Goal: MAX revenue push
- Inventory: Stock up everything
- Expect: 50-100 units sold per product
```

**Profitability:**
```
Product: Serum, Price 300K, COGS 100K

Daily sale (10% off):
- Sale price: 270K
- Margin: 170K ✓ Still OK

Weekly sale (25% off):
- Sale price: 225K
- Margin: 125K ✓ Acceptable (if volume 5x normal)

Mega sale (40% off):
- Sale price: 180K
- Margin: 80K ✓ Minimal, must have 10x volume to justify
```

**Inventory planning for sales:**
```
Normal daily sales: 10 units
Flash sale: Expect 50 units

Prep: Stock 100 units (10 days + 50 flash sale + buffer)
```

### 4.2. Pricing Consistency

**Challenge:** Different sàn have different costs
- Shopee fee: 1-6% (varies by category)
- Lazada fee: 1-5%
- TikTok: 2-5%
- Shipping cost varies

**Solution: Dynamic pricing strategy**

**Strategy 1: Price lowest on highest fee sàn**
```
Assume: Shopee 6% fee, Lazada 3% fee
COGS: 100K
Target margin: 100K (50%)

Lazada (lower fee, higher price):
Price: 200K
Net profit: 200K - 100K COGS - (200K × 3% fee) = 94K

Shopee (higher fee, lower price):
Price: 180K
Net profit: 180K - 100K COGS - (180K × 6% fee) = 69.2K

Problem: Customer buys on Shopee (cheaper), competitor undercuts on Lazada

Solution:
- Accept slight margin diff (180K on Shopee vs 200K Lazada)
- Or: Find cheaper COGS to support Shopee price
- Or: Use Shopee ads to drive volume (offset lower margin)
```

**Strategy 2: Consistency for brand trust**
```
Same price on all 3 sàn (absorb fee difference)

Pros:
- Customer won't think you favor one sàn
- Reduces competitor comparison
- Brand looks strong

Cons:
- Lower margin on high-fee sàn
- Requires higher COGS source

Decision: If high-margin products (>60%), use consistency
If low-margin products (30-40%), optimize per platform
```

## PHẦN 5: ALGORITHM & CÁC CÁCH TỐI ƯU

### 5.1. Shopee Algorithm (Cách sản phẩm được xếp hạng)

**Shopee algorithm = đánh trọng số:**

| Factor | Weight | How to optimize |
|--------|--------|---|
| **Conversion rate** | 40% | Better product quality + photos → higher conversion |
| **Shop rating** | 20% | Deliver on time, good customer service |
| **Recent sales** | 15% | Use ads & promotions to drive volume |
| **Chat response** | 10% | Respond <5 min |
| **Listing quality** | 10% | Complete info, good photos, detailed description |
| **Ship on time** | 5% | Set realistic delivery time, ship ASAP |

**Ranking = Score of above factors**

```
Conversion rate 60% (40% weight) → Score: 60 × 0.4 = 24 pts
Shop rating 4.7 (20% weight) → Score: (4.7/5) × 100 × 0.2 = 18.8 pts
Recent sales (15% weight) → Score: 15 pts (if >10 sales/week)
Chat response 95% (10% weight) → Score: 95 × 0.1 = 9.5 pts
Listing quality 90% (10% weight) → Score: 90 × 0.1 = 9 pts
Ship on time 99% (5% weight) → Score: 99 × 0.05 = 4.95 pts

Total score: ~81/100 → Rank in top search results
```

**How to game Shopee algorithm (ethically):**

1. **Boost conversion rate (40% weight):**
   - Use professional photos (bright, clear, multiple angles)
   - Write honest detailed description
   - Show testimonials in listing
   - Use "Shopee Guaranteed" badge (if possible)

2. **Maintain shop rating (20% weight):**
   - See section 1.2 (Shop Score)

3. **Recent sales momentum (15% weight):**
   - Use Shopee Ads to get initial sales
   - First 3 days critical: get 5-10 sales to trigger algorithm
   - Once algorithm boosts, organic sales follow

4. **Chat response (10% weight):**
   - Enable auto-reply
   - Have team respond within 5 minutes
   - Answer product questions thoroughly

5. **Listing quality (10% weight):**
   - Fill all attributes
   - 5+ images mandatory
   - 300+ word description
   - Use video if possible

6. **Ship on time (5% weight):**
   - Set shipping time realistically (2-3 days)
   - Ship within 24 hours (usually arrive early)

---

### 5.2. Lazada Algorithm

**Lazada = more focus on content score, less on conversion**

| Factor | Weight | How to optimize |
|--------|--------|---|
| **Content score** | 35% | Complete listing, good description, 5+ images |
| **Seller rating** | 25% | Same as Shopee |
| **Recent sales** | 20% | Similar to Shopee |
| **Price competitiveness** | 10% | Match or beat competitor price |
| **Chat response** | 10% | Respond quickly |

**Key difference:** Lazada reward good listings, Shopee reward conversions

**Strategy:**
- Lazada: Invest in perfect listing (photos, description, attributes)
- Shopee: Invest in sales velocity (ads, promotions)

### 5.3. TikTok Algorithm

**TikTok = Video algorithm, not e-commerce search**

| Factor | Weight | How to boost |
|--------|--------|---|
| **Watch time** | 30% | Make videos engaging, hold attention |
| **Engagement** | 25% | Get likes, comments, shares (trending content) |
| **Click-through** | 20% | Hook first 3 seconds, CTA clear |
| **Completion rate** | 15% | Keep video engaging throughout |
| **Share rate** | 10% | Make content shareable/relatable |

**TikTok strategy:**
- Copy trending sounds (algorithm LOVES trending)
- Make 15-30 second videos (optimal length)
- Engagement beats followers (100K followers, 1% engagement < 10K followers, 20% engagement)
- Post 3-5 times/week for consistency
- Reply to comments ASAP (boost engagement)

**Algorithm flow:**
```
You post video
↓
TikTok pushes to 500-1000 people (initial exposure)
↓
If 30% watch full video → TikTok pushes to 5000 people
↓
If 50% like/comment → TikTok pushes to 20K people
↓
If viral (10%+ traffic from FYP) → TikTok pushes to millions
```

**How to beat algorithm:**
- First 3 seconds CRITICAL (50%+ drop-off rate if not hooked)
- Use trending sounds (don't use original music)
- Make relatable/entertaining content (not just product promo)
- Post when audience active (6-10 PM)
- Use relevant hashtags (mix popular + niche)

## PHẦN 9: COMMON MISTAKES & HOW TO FIX

```
❌ MISTAKE #1: Setting unrealistic delivery time
   - Example: Claim "1-2 days" for HCMC but you ship in 3 days
   - Problem: Failed delivery metrics, shop rating drops
   - Fix: Set "2-3 days" HCMC, "3-5 days" provinces (ship within 1 day)

❌ MISTAKE #2: Ignoring chat messages
   - Example: Don't respond to customer questions >24 hours
   - Problem: Chat response rate drops, algorithm penalizes
   - Fix: Enable auto-reply, hire part-time CS person

❌ MISTAKE #3: Using same price across all sàn
   - Example: 300K on Shopee, Lazada, TikTok
   - Problem: High-fee sàn (Shopee 6%) = low margin
   - Fix: Dynamic pricing (200K Shopee, 220K Lazada, 210K TikTok)

❌ MISTAKE #4: Poor product photos
   - Example: Blurry, dark, product not clear
   - Problem: Low conversion rate (1% vs target 2-3%)
   - Fix: Invest in professional photography (or DIY with good lighting)

❌ MISTAKE #5: Not using ads when starting
   - Example: Rely 100% on organic
   - Problem: Takes 3-6 months to get algorithm momentum
   - Fix: Use Shopee Ads 50K-100K/month for first month (bootstrap sales)

❌ MISTAKE #6: Overselling (inventory mismatch)
   - Example: List 100 units on each sàn (300 total), only have 100
   - Problem: Customer buys on multiple sàn, you can't fulfill → refunds
   - Fix: Use Haravan/Nhanh.vn to sync inventory

❌ MISTAKE #7: Setting margins too low
   - Example: 15% margin to "compete"
   - Problem: Zero profit, can't scale or survive downturns
   - Fix: Aim 40-50% margin minimum (or find cheaper COGS)

❌ MISTAKE #8: Ignoring negative reviews
   - Example: Get 2-3 star review, don't respond
   - Problem: Other customers read negative review, lose sales
   - Fix: Always respond to negative reviews (explain, offer solution)
