# Thiết Kế Banner & Thumbnail Cho Thương Mại Điện Tử

## PHẦN 1: KÍCH THƯỚC BANNER THEO TỪNG PLATFORM

### 1.1 SHOPEE

#### Shop Banner (Main)
```
Kích thước: 1200x300 pixel (hoặc 1200x480 nếu muốn taller)
Tỷ lệ: 4:1 (ngang)
Dung lượng: < 5MB per file
Số lượng: Tối đa 5 banners (rotate)
Update frequency: 2-4 tuần / lần

PLACEMENT:
  - Hiển thị ở đầu shop page
  - Tất cả khách đều thấy trước tiên
  - Highest impact zone

BEST PRACTICES:
  - Sản phẩm featured hiển thị (hoặc shop logo)
  - CTA rõ ràng: "SHOP NOW" / "KHÁM PHÁ"
  - Text không quá nhiều (max 5-7 words)
  - Background: Solid color hoặc subtle pattern
```

#### Flash Sale Banner
```
Kích thước: 800x800 pixel (vuông)
Tỷ lệ: 1:1
Placement: Flash sale zone, campaign section
Dung lượng: < 2MB

CONTENT MUST-HAVE:
  - Discount percentage: "50% OFF" (bold, large)
  - Countdown timer: "SALE ENDS IN 23:45:32"
  - Product image (hoặc product category icon)
  - Color: Red, yellow (high urgency)
  - Font: Bold, readable từ 300px away

EXAMPLE LAYOUT:
┌──────────────────────────┐
│  🏷️ FLASH SALE 🏷️        │
│  [LARGE DISCOUNT %]      │
│      50% OFF             │
│                          │
│   [PRODUCT IMAGE]        │
│                          │
│  ⏱️ Ends in 2 hours ⏱️    │
│                          │
│  🔴 SHOP NOW 🔴         │
└──────────────────────────┘
```

#### Voucher Banner
```
Kích thước: 600x400 / 400x400 pixel (flexible)
Tỷ lệ: 1.5:1 hoặc 1:1
Placement: Voucher section
Content: Discount code, terms, benefit

DESIGN:
  - Code prominently: "CODE: SAVE20" (big, monospace font)
  - Benefit: "Giảm 200K cho order > 1M"
  - Expiration: "Hết hạn: 30/4/2024"
  - Brand logo (small)
```

## PHẦN 2: THIẾT KẾ BANNER BÁN HÀNG HIỆU QUẢ

### 2.1 VISUAL HIERARCHY & LAYOUT

#### The F-Pattern (Eye-tracking)
```
People scan webpages in an F-shape:
  1. Horizontal scan (top): Headline, logo
  2. Vertical scan (left): Navigation, text
  3. Horizontal scan (middle-bottom): Call-to-action

APPLY TO BANNER:
┌─────────────────────────────────┐
│ [Logo] HEADLINE [CTA]           │ ← Top horizontal
│                                 │
│ [PRODUCT]     BENEFIT TEXT      │ ← Left-to-right scan
│                                 │
│              [CALL-TO-ACTION]   │ ← Bottom focus
└─────────────────────────────────┘

DESIGN:
  - Logo top-left or top-center
  - Main message top or center
  - CTA button bottom-right or center
  - Product image main focus
```

#### Z-Pattern (Western reading direction)
```
Eyes follow Z-shape:

1. Top-left ──→ Top-right (left-to-right)
        ↘
2. Diagonal across
        ↘
3. Bottom-left ──→ Bottom-right

APPLY TO BANNER:
┌─────────────────────────────────┐
│ [LOGO]  →  [HEADLINE]           │ ← Top horizontal (left to right)
│                                 │
│           ↓ ↙                   │
│          [PRODUCT IMAGE]        │
│                                 │
│                  → [CTA]        │ ← Bottom horizontal (right)
└─────────────────────────────────┘

BEST FOR: Sale banners, product launches
```

#### Golden Ratio (Aesthetic placement)
```
Place important elements at 1.618 ratio points (natural-looking balance)

For 1200px wide:
  Critical points: 742px, 458px (magic 1.618 division)

For designers: Use tools like "Golden Ratio Calculator"
  Websites/apps make this automatic

PSYCHOLOGY: Feels naturally balanced, premium
```

### 2.3 TYPOGRAPHY (CHỮ)

#### Font Selection
```
RULE: Max 2-3 fonts per design
  - Font 1 (Headline): Bold, distinctive, readable
  - Font 2 (Body): Clean, accessible
  - Font 3 (Accent): Optional (less common)

FONT CATEGORIES:

1. SERIF (formal, luxury, tradition)
   - Example: Georgia, Garamond, Times New Roman
   - Use: Premium brands, formal campaigns
   - Vietnamese: Sử dụng font serif cho classic look

2. SANS-SERIF (modern, clean, tech)
   - Example: Arial, Helvetica, Open Sans, Roboto
   - Use: Most e-commerce (versatile)
   - Vietnamese: Best cho digital

3. SCRIPT (elegant, feminine, special occasions)
   - Example: Brush Script, Pacifico
   - Use: Valentine, gift, luxury
   - Vietnamese: Ít dùng (hard to read)

4. DISPLAY (creative, attention-grabbing)
   - Example: Bebas Neue, Playfair Display
   - Use: Sale, headline, special event
   - Vietnamese: Ok, nhưng test readability

VIETNAMESE FONTS:
  - Montserrat: Clean, modern
  - Lexend Deca: Friendly, accessible
  - Cabin: Geometric, balanced
  - Barlow: Contemporary
  - Try Google Fonts (free, Vietnamese support)
```

#### Font Sizing & Hierarchy

```
BANNER TYPOGRAPHY HIERARCHY:

PRIMARY HEADLINE (Product/Offer):
  - Size: 48-72px (desktop), 24-36px (mobile)
  - Weight: Bold (700+)
  - Line-height: 1.2 (tight)
  - Example: "KHUYẾN MÃI 50%"

SECONDARY HEADLINE (Descriptor):
  - Size: 28-40px
  - Weight: Semi-bold (600)
  - Example: "Cho tất cả các mặt hàng"

BODY TEXT (Details):
  - Size: 16-24px
  - Weight: Regular (400)
  - Example: "Hạn mức khuyến mãi: từ 100K đến 10M"

CTA TEXT (Button):
  - Size: 18-28px
  - Weight: Bold (700)
  - Example: "SHOP NOW"

MICROTEXT (Footnotes, terms):
  - Size: 12-14px
  - Weight: Light (300-400)
  - Example: "*Áp dụng cho hàng hóa được chọn"

COLOR CONTRAST RATIO:
  - Min 4.5:1 (WCAG AA standard)
  - Check với: contrast-ratio.com
  - Black on white: ✓ (21:1 excellent)
  - Dark gray (#333) on white: ✓ (12.6:1 good)
  - Light gray on white: ✗ (3:1 fail)
```

#### Readability Rules
```
✓ GOOD:
  - Line length: 50-75 characters (readable)
  - Line height: 1.4-1.6 (not cramped)
  - Letter spacing: 0.5-2px (not touching)
  - High contrast: Dark text on light bg
  - Generous padding: Space around text

✗ BAD:
  - Line length: 100+ characters (hard follow)
  - Line height: < 1 (cramped, hard read)
  - Letter spacing: 0 (squished)
  - Low contrast: Gray on gray
  - No padding: Text edge-to-edge
```

### 2.4 CTA BUTTON DESIGN

#### Button Anatomy

```
PERFECT CTA BUTTON STRUCTURE:

┌─────────────────────────────┐
│                             │
│      Padding-top: 12px      │
│      ┌──────────────────┐   │
│      │  Padding: 16px   │   │
│      │  SHOP NOW        │   │
│      │  (Button text)   │   │
│      └──────────────────┘   │
│      Padding-bottom: 12px   │
│                             │
└─────────────────────────────┘

DIMENSIONS:
  - Min height: 44px (mobile-friendly, easy tap)
  - Min width: 120px (not too narrow)
  - Padding: 12px vertical, 24px horizontal
  - Border-radius: 4-8px (slightly rounded)
```

#### Button Colors & Contrast

```
CTA BUTTON COLOR RULES:

1. HIGH CONTRAST REQUIRED
   - Button color ≠ background color (must pop)

   ✓ GOOD:
     Background: White
     Button: Red / Orange / Bold color

   ✗ BAD:
     Background: Gray
     Button: Dark gray (too similar)

2. COLOR PSYCHOLOGY FOR CTA
   - Red: Urgency, immediate action (SHOP NOW, BUY)
   - Green: "Go" signal, purchase positive (CHECKOUT)
   - Orange: Friendly, approachable (SHOP)
   - Blue: Trust, professional (LEARN MORE)
   - Black: Premium, powerful (EXCLUSIVE ACCESS)

3. BUTTON STATES:
   a) Default: Solid color
   b) Hover: Darker shade (-10% brightness)
   c) Active/Pressed: Darkest (-20%)
   d) Disabled: 50% opacity, gray

EXAMPLE STATE COLORS:
  Default:  #FF6B35 (Orange-red)
  Hover:   #E55A2B (darker)
  Active:  #CC4D21 (darkest)
  Disabled: #FF6B35 @ 50% opacity
```

#### Button Copy (Text)

```
ACTION-ORIENTED VERBS:

Best practice: Specific action verb, not generic

✓ STRONG CTA COPY:
  - "MUA NGAY" (BUY NOW)
  - "SHOP NGAY" (SHOP NOW)
  - "KHÁM PHÁ" (DISCOVER)
  - "TRỢ LỰC MIỄN PHÍ" (FREE CONSULTATION)
  - "ĐẶT MUA" (ORDER NOW)
  - "LƯU DANH SÁCH" (SAVE LIST)
  - "XOAY THÊM" (SPIN AGAIN) [for gamification]

✗ WEAK CTA COPY:
  - "CLICK" (Too generic)
  - "NEXT" (Vague)
  - "SUBMIT" (Cold, corporate)
  - "OK" (Doesn't encourage action)

URGENCY MODIFIERS:
  - "NGAY": SHOP NGAY, MUA NGAY (immediate action)
  - "MIỄN PHÍ": TRỢ LỰC MIỄN PHÍ (free appeal)
  - "HẠN" kỳ hạn: "MUA TRƯỚC 12/4" (scarcity)

LENGTH: 1-4 words max
```

### 2.5 WHITESPACE (Negative Space)

#### Whitespace Importance
```
WHITESPACE = Luxury perception

More whitespace = Premium brand
Less whitespace = Budget/clearance store

ECOMMERCE PERCEPTION:
  - High whitespace (50%+ empty): Luxury, premium (+40% perceived quality)
  - Medium whitespace (30-40%): Balanced, professional
  - Low whitespace (<30%): Urgent, sales-focused, budget (+10% perceived discount)

WHEN TO USE WHICH:
  - Tẻo hàng cao cấp: Generous whitespace
  - Flash sale/clearance: Minimal whitespace (full of info)
  - Regular promotion: Balanced whitespace
```

#### Whitespace Guidelines
```
PADDING (Border whitespace):
  - Sides: 40-60px (desktop), 20-30px (mobile)
  - Top/bottom: 30-50px
  - Around CTA: min 20px all sides

GAP BETWEEN ELEMENTS:
  - Headlines to body: 20px gap
  - Image to text: 30px gap
  - Text to CTA: 30-40px gap

RULE: Always have breathing room
  If cramped: Increase padding/gaps by 10-20px
```

## PHẦN 3: THUMBNAIL CHO VIDEO

### 3.1 TIKTOK / INSTAGRAM REELS THUMBNAIL

#### Structure
```
TikTok Thumbnail = First frame of video (auto-generated, or custom)

ELEMENTS NEEDED:

1. FACE (if you have one):
   - Large, centered, taking 40-60% of frame
   - Eye contact or shocked expression
   - No sunglasses / hat (if possible)
   - Lighting: Bright, visible

2. PRODUCT (if product-focused):
   - Prominent, clearly visible
   - Color: Contrasting to background
   - Position: Opposite face (if both present)

3. TEXT OVERLAY:
   - Max 3-4 words
   - Bold, readable font (min 24px)
   - High contrast color
   - Position: Top or bottom (not covering face)

4. BACKGROUND:
   - Plain color (easy to stand out in feed)
   - OR blurred (focus on subject)
   - High color saturation (catches eye)

LAYOUT EXAMPLE:
┌─────────────────────────────┐
│                             │
│  [SHOCKED FACE] [TEXT]     │
│     (60%)       (40%)      │
│                             │
│  [PRODUCT or CTA below]    │
│                             │
└─────────────────────────────┘

FORMULA: [Face + Shock/Excitement] + [Text: 3-4 words] + [Product if applicable]
```

#### Color & Contrast
```
CONTRASTING COLOR PAIRS (eye-catching):

✓ Good combos:
  - Black text on yellow background
  - White text on red background
  - White text on navy blue
  - Yellow text on black background
  - Green text on white background

✗ Bad combos:
  - Gray text on white (low contrast)
  - Blue text on black (nearly invisible)
  - Light gray on dark gray (blurry)

TEST: Squint at thumbnail, can you still read text?
  If no → increase contrast
```

#### TikTok Specific Tips
```
TIKTOK ALGORITHM FAVORS:
  1. Face-on thumbnails (humans engage more)
  2. Bright, saturated colors
  3. Short text (readable in 0.5 seconds)
  4. Trending aesthetics (match current TikTok style)

TRENDING THUMBNAILS (2024-2025):
  - Shocked/surprised face + text
  - Before-after split (left/right)
  - "Wait for the end..." text + question
  - Bold color blocks + centered subject
  - High energy (movement lines, action)

AVOID:
  - Blurry, dark, murky
  - Too much text
  - Faces looking away
  - Small product (hard to see)
  - Unprofessional / low quality
```

## PHẦN 7: A/B TESTING BANNER ELEMENTS

### 7.1 TESTABLE ELEMENTS

```
MAIN VARIABLES TO TEST:

1. HEADLINE / COPY
   Version A: "SALE 50% - LIMITED TIME"
   Version B: "KHUYẾN MÃI 50% - HỐM NAY THÔI"

   → Track: CTR (click-through rate), conversion rate

2. COLOR SCHEME
   Version A: Red + Gold (traditional, urgency)
   Version B: Blue + White (trust, premium)

   → Track: Time-on-page, engagement, conversion

3. CTA BUTTON PLACEMENT
   Version A: Bottom-right (standard)
   Version B: Center-bottom (balanced)

   → Track: CTA click rate, position bias

4. PRODUCT IMAGE
   Version A: Hero product on white background
   Version B: Lifestyle (person using product)

   → Track: CTR, time-on-page, conversion rate

5. TEXT AMOUNT
   Version A: Minimal (headline + CTA only)
   Version B: Full details (headline + benefit + urgency + CTA)

   → Track: Comprehension, conversion, bounce rate

6. DISCOUNT DISPLAY
   Version A: Percentage "50% OFF"
   Version B: Amount "Save 500K"

   → Track: Conversion rate, AOV (average order value)
```

---

### 7.2 A/B TEST FRAMEWORK

```
METHODOLOGY:

Platform: Run test on highest-traffic platform
  (e.g., Shopee flash sale, Facebook ads)

Duration: Minimum 1-2 weeks
  (Enough traffic to reach statistical significance)

Traffic split: 50/50
  - Version A: Half of traffic
  - Version B: Other half of traffic

Sample size: Minimum 500+ interactions per variation
  (Small samples = unreliable results)

SAMPLE CALCULATION:
  If normal CTR: 3%
  Want to detect: 1% improvement (4% CTR)
  Need sample size: ~3,000-5,000 clicks per variant
  If get 1% CTR: ~300,000 views per variant
```

---

### 7.3 METRICS TO TRACK

```
PRIMARY METRICS (Most important):

• CTR (Click-through rate)
  Formula: (Clicks / Impressions) × 100
  Example: 150 clicks / 5,000 views = 3% CTR
  Benchmark: 2-4% good, 5%+ excellent

• Conversion rate
  Formula: (Purchases / Clicks) × 100
  Example: 5 purchases / 100 clicks = 5% conversion
  Benchmark: 1-3% average, 5%+ excellent

• AOV (Average Order Value)
  Formula: Total revenue / Number of orders
  Example: 5M total / 10 orders = 500K AOV
  Goal: Increase AOV per test

SECONDARY METRICS (Context):

• Time on page: How long viewer spends
  More time = More engagement (usually good)
  Unless scrolling to find info (needs improvement)

• Bounce rate: % who leave without action
  Lower = Better
  Goal: < 50%

• Repeat visitor rate: % returning to banner
  Higher = Interest (will buy later)

STATISTICAL SIGNIFICANCE:

Only declare a winner if difference is statistically significant
(not just lucky variance)

Use A/B testing calculator:
  - Input: Conversion rate A, Sample size A
  - Input: Conversion rate B, Sample size B
  - Output: "Significant" or "Not significant"

DON'T END TEST TOO EARLY!
  Day 1: Version A looks 50% better
  Day 3: Version B catching up
  Day 7: Both nearly equal
  → Small sample size early = misleading
```

## PHẦN 8: BATCH DESIGN WORKFLOW (20+ BANNERS/TUẦN)

### 8.1 PRODUCTIVITY STRATEGY

```
GOAL: Create 20-30 banners per week (for multi-platform, multi-campaign)

WORKFLOW SYSTEM:

STEP 1: Template Creation (1 hour)
  - Create 1 master template in Canva
  - Setup: Grid, colors, fonts, spacing
  - Save as template
  - Duplicate 30x times

STEP 2: Batch Content Input (30 mins)
  - List all 30 variations needed
  - Spreadsheet: Headline | Subheading | CTA | Color | Product
  - Organize logically (by campaign, date, season)

STEP 3: Parallel Editing (3 hours)
  - Open all 30 canva templates
  - Edit in batches:
    Batch 1: Change all headlines (headlines in all 10, then switch batch)
    Batch 2: Change all subheadings
    Batch 3: Change all colors
    Batch 4: Change all CTAs
  - Faster than editing 1 fully, then next

STEP 4: Quality Check (1 hour)
  - Screenshot each banner at thumbnail size
  - Verify readability
  - Check for typos
  - Approve/reject/revise

STEP 5: Batch Export (30 mins)
  - Canva batch download (if available)
  - Or manual download all (faster than expected)
  - Organize by folder: [Campaign]/[Platform]/

TOTAL TIME: ~5-6 hours for 30 banners = 10-15 minutes per banner
  (vs. 30+ minutes if design each individually)

TOOLS TO SPEED UP:
  - Canva Magic Resize: 1 design → 5 platform sizes (1 minute)
  - Canva templates: Pre-built layouts save design time
  - Google Sheets + Canva integration: Auto-fill data
```

### 8.2 TEMPLATE STRUCTURE FOR REUSE

```
CANVA MASTER TEMPLATE SETUP:

Layer structure:
  1. Background layer (image or color)
  2. Shapes layer (rectangles, circles for design elements)
  3. Product image layer (empty, ready to insert)
  4. Text layers:
     - Headline (format: size, font, color)
     - Subheading
     - CTA button (shape + text)
     - Urgency text (optional)
  5. Branding layer (logo, locked)

WHY THIS STRUCTURE:
  - Consistent spacing (every element aligned)
  - Easy to edit (change text without touching design)
  - Quick duplication (duplicate → change text only)
  - Version control (original template untouched)

BATCH EDIT WORKFLOW:
  1. Select all 30 "Headline" text boxes
  2. Paste list of headlines
     → Canva auto-fills (if using Smart Paste)
  3. Select all "Product images"
  4. Drag-drop product images
  5. Select all "CTA buttons"
  6. Change text to CTA options

TIME SAVED: ~20 minutes per 30 designs
```
