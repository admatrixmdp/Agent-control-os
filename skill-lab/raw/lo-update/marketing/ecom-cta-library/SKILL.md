## PLACEMENT STRATEGY

### Above-the-fold CTA
- **Goal:** Maximize initial conversion
- **Best for:** Time-sensitive offers, high intent
- **Example:** "Mua ngay - Chỉ còn 2 giờ"

### Mid-page CTA
- **Goal:** Secondary conversion point
- **Best for:** Nurturing, additional info
- **Example:** "Tìm hiểu thêm" / "Xem chi tiết"

### End-of-content CTA
- **Goal:** Final ask after education
- **Best for:** Sales page, long-form content
- **Example:** "Bắt đầu ngay"

### Floating/Sticky CTA
- **Goal:** Always visible, persistent
- **Best for:** High-value offers
- **Example:** "📱 Chat với tôi" (sticky at bottom)

### Exit-intent CTA
- **Goal:** Last-chance save
- **Best for:** Cart abandonment, lead capture
- **Example:** "Đợi! Giảm 50% nếu bạn đơn ngay"

### Pop-up CTA
- **Goal:** Grab attention
- **Best for:** Email list building, limited-time offer
- **Example:** "Tham gia danh sách - Nhận coupon 100k"

## A/B TEST CTA PAIRS

### Test set 1: Direct vs Benefit

```
A: "Mua ngay"
B: "Mua ngay - Freeship 100k"

Expected winner: B (more benefit stated)
```

### Test set 2: Action verb vs Emotional

```
A: "Đặt hàng"

Expected winner: Depends on audience (B for Gen Z)
```

### Test set 3: Long vs Short

```
A: "Mua hôm nay, freeship, tặng quà"
B: "Mua ngay"

Expected winner: Depends on placement
(A for email, B for social)
```


## CONVERSION-OPTIMIZED CTA FORMULA

**Step 1: Start with action verb**
```
❌ "Click"
✓ "Mua" / "Đặt" / "Tải" / "Nhập"
```

**Step 2: Add benefit/offer (if space)**
```
✓ "Mua ngay"
✓ "Mua ngay - Freeship"
✓ "Mua trước khi hết"
```

**Step 3: Consider adding emoji (for casual brands)**
```
✓ "Mua ngay 🛒"
✓ "Nhận coupon 🎁"
✓ "Chat với tôi 💬"
```

**Step 4: Test length vs specificity**
```
Short (good for buttons): "Mua ngay"
Medium (good for text): "Mua ngay - Freeship"
Long (good for email): "Mua hôm nay và nhận freeship 100k + quà tặng 500k"
```

## MOBILE VS DESKTOP CTA

### Desktop
- Can be longer (button has more space)
- Example: "Mua Ngay - Freeship + Quà Tặng"

### Mobile
- Must be shorter (button area smaller)
- Larger font/touch target needed
- Example: "Mua Ngay"

**Solution:** Responsive button text
```
Desktop: "Mua Ngay - Freeship + Quà Tặng"
Mobile: "Mua Ngay"
(Same link, different text)
```

## AVOID THESE CTA MISTAKES

❌ "Click here"
- Too generic, no action stated

❌ "Submit"
- Sounds cold, corporate

❌ "No"
- Should never offer "No" option
```
Instead of:
[Yes] [No]

Do this:
[Buy Now] [Learn More]
```

❌ Vague language
```
❌ "Continue"
✓ "Checkout"

❌ "Next"
✓ "See Details"
```

❌ All CAPS
```
❌ "CLICK HERE NOW!!!"
✓ "Mua Ngay"
```

❌ Multiple conflicting CTAs
```
❌ [Mua Ngay] [Xem Thêm] [Tư Vấn] [Chat]
   (khách choáng, không biết click cái nào)

✓ [Mua Ngay] (primary CTA)
   [Xem Chi Tiết] (secondary, smaller)
```

## TRACKING CTA PERFORMANCE

### Metrics to track:
1. **Click-through rate (CTR)**
   - Target: > 2% for good CTA
   - Compare different CTA texts

2. **Conversion rate**
   - From CTA click → Purchase
   - CTA close to product = higher conversion

3. **CTA placement impact**
   - Above fold vs below fold
   - Floating vs fixed

4. **Button color impact**
   - Red vs green vs blue
   - Track by segment

### Dashboard to build:
```
CTA Text | CTR% | Conv% | Position | Color
"Mua Ngay" | 3.2 | 8.5 | Top | Red
"Mua Ngay -50%" | 4.1 | 9.2 | Top | Red
"Tìm Hiểu" | 2.1 | 4.3 | Bottom | Blue
```
