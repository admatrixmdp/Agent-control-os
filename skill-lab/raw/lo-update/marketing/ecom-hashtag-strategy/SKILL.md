# HASHTAG STRATEGY - CHUYÊN SÂU TOÀN DIỆN

## TỔNG QUAN: TẠI SAO HASHTAG QUAN TRỌNG

### Impact of hashtags:
- Instagram: Posts with hashtags get 30% more engagement
- TikTok: Hashtag trong description = better FYP (For You Page) chance
- Discoverability: #123 helps customers find you vs algorithm alone
- Community: Hashtag unites similar interests → potential customers gather

### Hashtag goals:
1. **Reach:** Mở rộng audience (trending, popular hashtags)
2. **Targeting:** Tìm đúng audience (niche hashtags)
3. **Community:** Tham gia community (community hashtags)
4. **Branding:** Tạo identity riêng (branded hashtags)

## INSTAGRAM HASHTAG STRATEGY

### Best practices:

**Quantity:** 20-30 hashtags per post
- Too few (<5): Low reach
- Too many (>30): Looks spammy, Instagram may suppress
- Sweet spot: 20-30

**Placement:** 2 options

Option A (Most common):
```
[Caption with 1-2 sentences]
[Blank line]
[20-30 hashtags in comment below]
```

Option B (In caption):
```
[Caption text]
[#hashtag1 #hashtag2 #hashtag3...]
```

**Why separate:** Instagram shows cleaner caption, hashtags don't clutter

### Hashtag tier strategy (Quality mix):

**Tier 1: Big hashtags (1M+ posts)**
- Example: #ThươngMạiĐiệnTử (100M+ posts), #TMĐTVN (50M+ posts)
- Pros: High reach, brand visibility
- Cons: High competition, hard to rank
- Use: 2-3 only (for brand awareness)

**Tier 2: Medium hashtags (100K-1M posts)**
- Example: #BánHàngOnline (500K posts), #ShopeeVN (800K posts)
- Pros: Good balance reach vs competition
- Cons: Still competitive
- Use: 5-7 (for reach with decent ranking chance)

**Tier 3: Niche hashtags (<100K posts)**
- Example: #áokhoáctheuthao (15K posts), #skincarevietnam (45K posts)
- Pros: Less competition, high conversion rate (targeted audience)
- Cons: Lower reach per hashtag
- Use: 10-15 (for targeting right audience)

**Tier 4: Branded hashtag (Your own)**
- Example: #mỹphẩmvanity, #shopthôngminh
- Pros: Create identity, easy to track (all posts from this hashtag = brand-related)
- Cons: Low reach initially, build over time
- Use: 1-2 (your main branded hashtag + campaign hashtag if any)

**Mix example for balanced strategy:**
```
- Tier 1 (1M+): 2-3 hashtags
- Tier 2 (100K-1M): 5-7 hashtags
- Tier 3 (<100K): 10-15 hashtags
- Tier 4 (Branded): 1-2 hashtags
Total: 18-27 hashtags
```

### Hashtag rotation (Don't repeat every post):

**Mistake:** Using exact same 30 hashtags on every post
- Result: Instagram may see as spam
- Algorithm penalty: Lower reach

**Strategy:** Rotate hashtags
- Create 3-5 hashtag sets of 20-30 each
- Rotate every post or every 3 posts
- Example:
  ```
  Post 1: Set A (Tier 1: #TMĐT, #BánHàng + Niche + Branded)
  Post 2: Set B (Tier 1: #ShopeeVN, #LazadaVN + Niche + Branded)
  Post 3: Set C (Tier 1: #OnlineBusiness, #Entrepreneur + Niche + Branded)
  Post 4: Back to Set A
  ```

### Banned hashtags (Avoid):

Instagram has shadow-ban system for some hashtags:
- **Spam hashtags:** #Follow #Like #Comment (overused for engagement pods)
- **Controversial:** Politically sensitive, hate speech hashtags
- **Sexual:** Adult content hashtags
- **Promotional spam:** #BuyFollowers #GetLikes #BotServices

**Check if hashtag is banned:**
1. Search hashtag on Instagram
2. If no recent posts or "Posts are hidden" → Likely banned
3. Avoid if unsure

### Hashtag research (Find good ones):

**Method 1: Competitor analysis**
```
1. Find 5-10 competitors in your niche
2. Visit their top posts
3. Screenshot hashtags they use
4. Note which hashtags appear repeatedly (likely high-performing)
5. Add to your hashtag sets
```

**Method 2: Hashtag suggestion tools**

Tools:
- Instagram's search bar (auto-suggest)
- All Hashtag (allhashtag.com)
- Hashtagify (hashtagify.me)
- Later (later.com/hashtag-generator)

Process:
```
1. Search main hashtag (#áokhoác)
2. Tool shows related hashtags + post count
3. Check engagement (usually related = high engagement)
4. Add top 5-10 related ones to your set
```

**Method 3: Community hashtags**
```
Search: #áokhoácVN #throiVietnam #fashionbloggerVN
Note: Posts using community hashtag will find you
Join community = build authority
```

## TIKTOK HASHTAG STRATEGY

### Key differences vs Instagram:

**TikTok algorithm:**
- Not primarily hashtag-driven (unlike Instagram)
- Sound/music + watch time = more important
- BUT hashtag helps: FYP categorization, searchability

**Quantity:** 3-5 hashtags (vs Instagram's 20-30)
- More = not better on TikTok
- TikTok values quality over quantity
- Focus on most relevant ones

**Placement:** In caption or comment
```
"[Video caption + content]
#hashtag1 #hashtag2 #hashtag3 #hashtag4 #hashtag5"
```

### TikTok hashtag tiers:

**Tier 1: FYP (For You Page) hashtags**
- Example: #FYP #ForYou #FYPViralOnTikTok #ForYouPage
- Posts: 10M-100M+
- Purpose: Boost chance of appearing on FYP
- Use: 1-2

**Tier 2: Trending/Challenge hashtags**
- Example: #TikTokChallenge, #NewDance, #FitnessChallenge
- Posts: 1M-100M
- Purpose: Participate in trends, viral potential
- Use: 1-2 (only if relevant to your content)

**Tier 3: Niche/Interest hashtags**
- Example: #skincareroutine #beautyblogger #makeup #kdrama
- Posts: 100K-1M
- Purpose: Reach interested audience
- Use: 1-3

**Tier 4: Branded hashtag**
- Example: #shopvanity #beautyfix
- Purpose: Build brand community
- Use: 1

### Example TikTok hashtag set:

```
#FYP #skincareroutine #beautytiktok #makeupover40 #skincarehacks #shopvanity

(Total: 6 hashtags - focused, relevant)
```

### Best time to post on TikTok:

- **9 AM - 3 PM:** Lunch break, break time (high engagement)
- **7 PM - 11 PM:** Evening scrolling (highest engagement, especially Gen Z)
- Avoid: 12 AM - 6 AM (dead hours)

## FACEBOOK HASHTAG STRATEGY

### Important note:
Hashtags less effective on Facebook vs Instagram/TikTok
- Facebook algorithm prioritizes: Comments, shares, saves (not hashtags)
- Hashtags can help with discoverability but secondary

### Best practice:

**Quantity:** 3-5 hashtags (minimal)

**Placement:** At end of caption or in comment

**Focus:** Community hashtags, brand hashtags

Example:
```
"[Post content]

#communityname #thẻđồng #hashtag4"
```

### When to use hashtags on Facebook:

- **Facebook Groups:** Use relevant to group topic
- **Page posts:** Use if you want external reach beyond followers
- **Events:** Use to help people discover event
- **Marketplace:** Use to help categorization (minimal help)

**Better strategy for Facebook:** Focus on:
- Compelling copy
- Good visuals
- Engagement (replies, comments)
- Shares to groups/friends

## YOUTUBE HASHTAG STRATEGY

### Where hashtags appear:

1. **Video tags** (Hidden, for algorithm)
   - Up to 500 characters per tag
   - Example: "skincare routine", "affordable products", "for beginners"
   - Not visible to viewers

2. **Hashtags in title/description** (Visible)
   - Show as clickable links above video title
   - Example: "#Skincare #BeautyRoutine #AffordableProducts"
   - Limit: 3 clickable hashtags recommended

### Best practice:

**Video tags (hidden):**
- 8-12 tags per video
- Mix: Broad + specific keywords
- Example tags:
  ```
  skincare, skincare routine, skincare for beginners, face care,
  affordable skincare, korean skincare, budget beauty, beauty hacks
  ```

**Description hashtags (visible):**
- 2-3 hashtags at top of description
- Example:
  ```
  "#Skincare #BeautyRoutine #AffordableProducts

  In this video I share my complete skincare routine..."
  ```

### Research YouTube tags:

1. Find similar videos (competitors)
2. Check their tags (use YouTube inspector or VidIQ tool)
3. Add relevant ones to your tags

**Tools:**
- TubeBuddy (tubebuddy.com)
- VidIQ (vidiq.com)
- YouTube itself (search autocomplete shows popular searches)

## BRANDED HASHTAG STRATEGY

### Why create branded hashtag:

1. **Build community:** Customers use your hashtag → UGC (User Generated Content)
2. **Easy tracking:** All posts using hashtag = your community
3. **Brand identity:** Unique to your brand
4. **Viral potential:** If hashtag catches on, organic reach explodes

### How to create branded hashtag:

**Characteristics of good branded hashtag:**
- Short (2-5 words max)
- Memorable (easy to spell, pronounce)
- Unique (not already popular)
- Relevant to brand/business
- Works across languages (if international)

**Examples:**
```
Good:
#shopvanity (shop name + meaning)
#mynailstory (emotional, memorable)
#fashionfix (alliteration, catchy)
#beautyjourneys (specific audience)

Avoid:
#bestskincare (too generic, low hashtag power)
#shop123 (meaningless, hard to remember)
#buystuff (no personality)
```

### Launch branded hashtag:

**Step 1: Create it**
```
Decide: #brandname + keyword
Example: #shopvanitycare
```

**Step 2: Promote it**
```
- Use in every post for 3-6 months consistently
- Encourage customers: "Use #shopvanitycare and tag us!"
- Feature best #shopvanitycare posts on your page (encourage others to use)
- Run contest: "Use #shopvanitycare to enter giveaway"
```

**Step 3: Track growth**
```
Search hashtag monthly
Chart: #posts using hashtag
Goal: 100+ posts/month after 6 months
```

### Example branded hashtag campaign:

```
Launch post:
"📢 Calling all beauty lovers!
Use #shopvanitycare when you post with our products.
Share your beauty journey + get featured on our page!

Best post this month wins 1M gift voucher 🎁"

Results after 3 months:
- 500+ posts using hashtag
- Increased brand awareness
- UGC content for future posts
```

## HASHTAG RESEARCH WORKFLOW

### Step 1: Analyze your niche (Weekly)

```
1. Identify 5-10 top competitor accounts
2. Check their recent posts (last 2 weeks)
3. Extract hashtags from high-performing posts
4. Copy into spreadsheet
5. Note: Did this post go viral? (Check like/comment count)
6. Prioritize hashtags from viral posts
```

### Step 2: Research tools (Monthly)

```
1. Pick 1-2 main keywords for your business
   Example: "skincare" + "affordable"
2. Use tool (All Hashtag, Later, TubeBuddy)
3. Search: #affordable skincare
4. Tool shows: Related hashtags + post volume + growth rate
5. Add top 10 related to your set
```

### Step 3: Build your hashtag sets (Quarterly)

```
1. Consolidate: Combine hashtags from step 1+2
2. Organize by tier (1,2,3,4)
3. Create 3-5 sets (rotate between posts)
4. Test performance (track which set gets better reach)
5. Refine: Keep good, remove underperforming
```

### Step 4: Track performance (Monthly)

```
Track:
- Reach per post
- Engagement per post
- Compare: Posts with tier 1 vs tier 3 hashtags
- Which hashtag sets perform best?
- Adjust mix accordingly

Tool: Instagram Insights, TikTok Analytics
```

## HASHTAG BEST PRACTICES

### DO:
✓ Use mix of tier 1, 2, 3, 4 hashtags
✓ Rotate hashtag sets to avoid spam flag
✓ Research before adding (avoid banned hashtags)
✓ Use branded hashtag consistently
✓ Engage with community hashtags (follow them, like/comment posts)
✓ Create campaign hashtags for limited-time offers
✓ Monitor which hashtags drive traffic/conversions
✓ Update hashtag mix quarterly based on performance

### DON'T:
✗ Use same 30 hashtags on every post
✗ Use irrelevant hashtags just for reach
✗ Overuse trending hashtags if not relevant
✗ Spam hashtags (50+ on Instagram, 10+ on TikTok)
✗ Use all Tier 1 hashtags (too competitive, hard to rank)
✗ Use banned/shadow-banned hashtags
✗ Copy exact hashtag set from competitor
✗ Ignore platform differences (Instagram ≠ TikTok strategy)

## HASHTAG MISTAKES TO AVOID

### Mistake 1: All hashtags, no caption
```
❌ Post: [Just photo + 30 hashtags]
✓ Post: [Thoughtful caption] [hashtags in comment]
```

### Mistake 2: Irrelevant hashtags for reach
```
❌ Fashion brand: #football #soccer #gaming (to get reach)
✓ Fashion brand: #fashion #style #streetwear (relevant to audience)
```

### Mistake 3: Ignoring engagement rate
```
❌ Using popular hashtag with 10M+ posts but only 2% engagement
✓ Using niche hashtag with 50K posts but 15% engagement (better conversion)
```

### Mistake 4: Not updating hashtag strategy
```
❌ Using same hashtags for 2+ years
✓ Review & update hashtags quarterly based on performance
```
