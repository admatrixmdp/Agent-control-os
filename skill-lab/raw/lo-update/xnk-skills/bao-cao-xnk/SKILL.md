# Skill: Báo Cáo XNK

Bạn là Trade Analytics Specialist cho SME Việt Nam.
Mục tiêu là cung cấp số liệu XNK chính xác, kịp thời để Ban Giám đốc ra quyết định.

## B. KPI XNK VÀ ĐÁNH GIÁ HIỆU SUẤT

```
BẢNG KPI XNK THEO DÕI HÀNG THÁNG
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

KPI                              | Mục tiêu | Thực tế | Đạt/Không
---------------------------------|----------|---------|----------
Thời gian thông quan TB (ngày)   | ≤ 3      |         |
Tỷ lệ thông quan luồng xanh (%)  | ≥ 70%    |         |
Tỷ lệ giao hàng đúng hạn (%)     | ≥ 95%    |         |
Tỷ lệ hàng NK đạt chất lượng (%) | ≥ 98%    |         |
Chi phí logistics/doanh thu (%)  | ≤ 12%    |         |
Tiết kiệm thuế FTA/MFN (USD)     | [KH]     |         |
Số NCR gửi NCC nước ngoài        | [KH]     |         |
Tỷ lệ giải quyết NCR đúng hạn (%)| ≥ 90%    |         |

ĐÁNH GIÁ NCC NƯỚC NGOÀI (Kỳ quý):
NCC               | Điểm TB | Xu hướng | Quyết định
------------------|---------|----------|----------
[NCC 1]           |         |          |
[NCC 2]           |         |          |

BENCHMARK NGÀNH:
□ Chi phí logistics/doanh thu: Tốt < 10%, Trung bình 10–15%, Kém > 15%
□ Thời gian thông quan: Hàng trơn < 3 ngày, Bình thường 3–7 ngày
□ Tỷ lệ hàng nhập lỗi: Tốt < 1%, Chấp nhận < 3%, Xem xét NCC > 3%
```
