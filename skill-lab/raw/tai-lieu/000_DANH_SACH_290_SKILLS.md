## NGUYÊN TẮC CHUNG (áp dụng cho mọi skill)

- **Frontmatter chuẩn**: name + description (Vietnamese, có trigger phrase đầy đủ)
- **80-150 dòng / SKILL.md**
- **MCP-first**: Hướng dẫn dùng Slack/Gmail/Calendar/Drive/Notion/Sheets connectors
- **API fallback**: Có phần "Nếu cần làm sâu hơn" — gọi REST API qua Python/bash
- **Quy trình 4-6 bước rõ ràng**
- **Output**: nêu rõ format (Markdown / HTML / Excel / PDF / Slide)
- **Checklist cuối skill** trước khi giao kết quả
